# Release Notes v5.20.5

### 🔐 Integrasi Baileys getMessage Callback & Dukungan LID DM
- **Dukungan Baileys getMessage Store:**
  - Menghubungkan fungsi callback `getMessage` pada `makeWASocket` ke database/in-memory store agar Baileys dapat mendekripsi kembali pesan retry, multi-device, dan media sekali lihat (*View Once*).
- **Dukungan Private Chat Identitas LID:**
  - Menambahkan pengenalan format JID `@lid` pada deteksi chat pribadi (DM) agar pesan dari pengguna dengan privasi nomor telepon tetap diproses dengan benar.
