## 🐛 Bug Fix — Owner Commands (CRITICAL)

### Root Cause
`src/utils/permissions.js` — fungsi `isOwner()` hanya memanggil `normalizeNumber()` pada **seluruh string** `OWNER_NUMBER` sekaligus (misal `"6285172013920, 279177622220923@lid"`) tanpa di-split per koma. Hasilnya berupa satu angka gabungan yang tidak pernah cocok dengan nomor siapapun.

Semua owner commands yang melakukan double-check `if (!isOwner(sender))` di dalam `execute()` selalu mendapat `false` → hanya balas emoji `🚫` → return.

**Commands yang terdampak:** `.sleep`, `.wake`, `.restart`, `.shutdown`, `.eval`, `.bc`, `.delete`

### Fix
`src/utils/permissions.js` — `isOwner()` sekarang:
- Split `OWNER_NUMBER` by koma
- Trim whitespace + strip non-digit dari setiap entri
- Cocokkan satu-per-satu dengan sender number

## ✨ New Features

### 🌐 Translate — `.tr`
- **File:** `src/commands/utility/translate.js`
- **Aliases:** `tr`, `terjemah`, `terjemahkan`
- Pakai Google Translate unofficial API (gratis, no key)
- 12+ bahasa: id, en, ja/jp, ko/kr, zh/cn, ar, es, fr, de, ru, pt
- Mode: `.tr en [teks]` atau reply pesan + `.tr jp`
- Auto-detect bahasa sumber, tampilkan flag emoji
- Max 3000 karakter

### 🖼️ Quote Card — `.quote`
- **File:** `src/commands/media/quotecard.js`
- **Aliases:** `quote`, `qcard`, `kartuquote`
- Generate kartu quote aesthetic menggunakan Sharp + SVG (zero new deps)
- 8 curated dark palettes (violet, github dark, navy red, forest, purple, gold, ocean, crimson)
- Decorative quote marks dengan glow effect
- Auto text wrapping
- Nama pengirim otomatis dari WA atau quoted participant
- Max 400 karakter

### ✝️ HKBP Theology Bot — `.hkbp`
- **File:** `src/commands/ai/hkbp.js`
- **Aliases:** `teologi`, `alkitab`, `firman`, `tanya-hkbp`
- Powered by Gemini 2.5 Flash dengan system prompt teologi khusus
- Topik: Alkitab & eksegesis, doktrin HKBP, liturgi & Buku Ende, sejarah Nommensen, sakramen, etika Kristen
- Memory terisolasi per chat (topic: `hkbp`) — tidak bercampur dengan AI umum
- Bahasa Indonesia + istilah Batak bila relevan
