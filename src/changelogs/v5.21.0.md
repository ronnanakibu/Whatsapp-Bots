# Release Notes v5.21.0

### ⚡ Fitur Baru: Pengaturan Kecepatan Stiker Animasi & Video (`--s<multiplier>x`)
- **Parameter Pengatur Kecepatan (*Speed Up / Slow Down*):**
  - Menambahkan parameter `--s<angka>x` atau `--s<angka>` pada perintah `.sticker` / `.s` untuk mengubah kecepatan stiker animasi / video.
  - Contoh penggunaan:
    - `.s --s2x` (Mempercepat animasi 2x lipat)
    - `.s --s1.5x` (Mempercepat animasi 1.5x lipat)
    - `.s --s3x` (Mempercepat animasi 3x lipat)
    - `.s --s0.5x` (Memperlambat animasi menjadi setengah kecepatan / slow motion)
- **Kompatibilitas Penuh:**
  - Dapat digabungkan dengan parameter lain seperti `--1` (rasio asli), `--rmbg` (hapus background otomatis), dan `--lq` (kualitas rendah), serta teks meme atas | bawah.
