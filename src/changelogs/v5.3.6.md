# Changelog v5.3.6 — YouTube Age-Gate Format Compatibility

## Bug Fixes
- **Reverted extractor client to android,web**:
  - **Issue**: Setting the extractor player client to `ios,android` (in version 5.3.5) caused age-restricted videos (which require age verification cookies) to fail extraction with the error `Requested format is not available`. This occurs because the iOS client endpoints do not support/accept YouTube session cookies for age gating, returning zero streams/formats to yt-dlp.
  - **Fix**: Reverted the player client string back to `'youtube:player_client=android,web'` in both `ytdlpGetAudioUrl` and `ytdlpStream` inside [ytdlp.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/services/ytdlp.js). This restores complete compatibility with age-gate bypass cookies.
  - **Note**: The download buffer size (`256k`) and FFmpeg thread queue size (`4096`) optimizations remain active, ensuring lag-free streaming once the stream starts.
