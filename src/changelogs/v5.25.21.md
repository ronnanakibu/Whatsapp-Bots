# v5.25.21 (Intelligent Document Extension Resolver & Auto-Heal)

## Features & Improvements
- **Smart Extension & Format Recognition**: Fixed an issue where documents saved without an explicit filename fallback to a `.bin` extension. All stored materials now intelligently determine their accurate format (PDF, Word, Excel, PowerPoint) from their media signatures.
- **Title-Based Document Naming**: Stored documents are now saved and delivered using their user-assigned titles and proper extensions (e.g., `modul_praktikum_elektronika.pdf`), allowing instant one-tap preview and opening directly within WhatsApp.
- **Automatic Document Self-Healing**: Existing notes previously saved with generic `.bin` filenames will now automatically heal and update in the vault with their proper document extensions upon retrieval.
- **Clean Caption Presentation**: Removed redundant bracket wrapping around document type badges for a clearer and more polished card layout.
