# Changelog - v5.3.25

## [5.3.25] - 2026-06-16

### Added
- **Android Radio Client Phase 2 Integration:**
  - Configured background execution services and media key receivers in `AndroidManifest.xml` via `audio_service`.
  - Added native `just_audio` playback logic inside `RadioAudioHandler`.
  - Configured normalized `User-Agent` headers (`android-radio-client`) on all stream requests to satisfy server bot-filtering requirements.
  - Implemented Dio-based `ApiClient` to poll `/status` from the self-hosted compute backend.
  - Added robust *stale-while-revalidate* BLoC polling logic with auto-offline states to ensure persistent UI rendering and connection error indicators.
  - Cleaned up typos and bound dynamic status outputs (FFMPEG & WA BOT online/offline) in `RadioScreen`.
  - Fixed initialization freeze on Android by modifying `MainActivity.kt` to extend `AudioServiceActivity` instead of `FlutterActivity`.
