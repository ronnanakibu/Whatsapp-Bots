# v2.1.0 (4 Juni 2026) — Weather Fallback & Timezone Fix

### 🚀 Update & Peningkatan:
- **Multi-Engine Weather Fallback**: Mengintegrasikan Google Weather API (menggunakan Maps Key) & WeatherAPI.com sebagai fallback otomatis jika Open-Meteo mengalami gangguan (502 Bad Gateway).
- **Redundant Geocoding**: Mendukung geocoding cadangan via WeatherAPI jika server Open-Meteo Geocoding mati.
- **Hourly Forecast Fix**: Memperbaiki bug index pada prakiraan per jam terdekat dengan mencari jam dengan selisih waktu terkecil.
- **Auto Timezone Translation**: Konversi dinamis waktu matahari terbit/terbenam dari ISO ke format lokal (WIB/target local time).
- **Weather Source Footnote**: Menampilkan footnote sumber data cuaca aktif di bagian bawah pesan.
