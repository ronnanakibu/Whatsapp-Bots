# v5.23.5 (Bootstrap Self-Healing Disk Sanitizer & Cloud Vault Auto-Migrator)

## Features
- **Cloud Vault Auto-Migrator**: Automatically scans and transfers legacy offline View Once and deleted media archives to the private cloud channel during startup, guaranteeing zero media loss while freeing server storage.

## Fixes
- **Fatal Stream Crash Elimination**: Added graceful fault handling for internal log streams, ensuring that sudden disk space constraints never cause fatal unhandled process crashes.
- **Aggressive Bootstrap Cache Sanitizer**: Pre-clears stale incoming chat media caches and rotates large log files synchronously before engine initialization, reclaiming hundreds of megabytes instantly on launch.
