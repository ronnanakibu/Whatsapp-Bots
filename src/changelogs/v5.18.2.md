# Release v5.18.2

### 🌟 New Features & Enhancements
* **Hermes Agent Reasoning Control**: Added dynamic reasoning mode activation via `.hermes reasoning true / false`. Users can now turn on/off the reasoning process header (`Thought for...`) per chat session.
* **AI Model Fallback Hardening**: Updated multi-agent intelligence routing and model fallback chains to prevent failure cascading and ensure resilient responses.
* **Clean Response Formatting**: Ensured reasoning headers are strictly displayed only when enabled and reasoning steps are generated.
