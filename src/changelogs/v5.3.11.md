# Changelog v5.3.11

## 🚀 RonnBot Radio V2 Backend Layer & Telemetry Integration

This release integrates the V2 backend architecture layers directly inside the WABOT2.0 codebase, replacing the local SQLite query endpoints under `/api/v2` with a robust PostgreSQL and Redis-backed community architecture.

### Key Changes:

1. **PostgreSQL Schema Setup (Prisma)**
   - Added `prisma/schema.prisma` mapping `User`, `UserAccount` (for credential linking), `UserStats`, `UserPresence`, `ChatMessage`, `ChatReaction`, `ListenerSession` (with platform/source/ipHash tracking), `Achievement`, `UserAchievement`, `SongReaction`, `ActivityFeed`, `Notification`, `WrappedCache`, and `CommunityWrapped` structures.
2. **Layered Services & Repositories**
   - Added data repositories: `user.repository.js` and `chat.repository.js`.
   - Added business layer services: `user-v2.js`, `chat-v2.js`, and `media.js` (validating image boundaries and scaffolding avatar/banner storage pipelines).
3. **Decoupled Event Bus**
   - Added `events/bus.js` to distribute system lifecycles (such as `chat.message`) without coupling service routes.
4. **Upgraded API Routes & Sockets**
   - Integrated V2 routes and Socket.IO namespaces (`/chat`, `/presence`, `/song-reactions`) inside WABOT2.0's Express boot in `radio.js`.
   - Bridged legacy authenticate middleware using dynamic JID payload mapping so guest UUID profiles auth cleanly without code restructuring.
5. **Logs Archiver Scheduler**
   - Configured a background scheduler exporting daily chat room history into `chatlogs/YYYY-MM-DD.md` markdown files.
6. **Docker & Local Deployment**
   - Added `docker-compose.yml` to orchestrate local Postgres and Redis database containers.
