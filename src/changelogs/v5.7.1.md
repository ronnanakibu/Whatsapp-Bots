# v5.7.1 — Spotify Radio Sync, Weekly Recap & Direct WhatsApp Error Alerts

**Release Date:** 2026-06-19

## ✨ Fitur Baru & Peningkatan

### 1. 🔄 Realtime Spotify Radio Sync — `.playowner`
- **Fungsi:** Menyambungkan pemutar lagu Spotify milik Owner dengan saluran Radio Bot secara otomatis dan realtime.
- **Fitur:**
  - Melacak pergantian lagu Spotify secara langsung menggunakan status Discord Rich Presence.
  - Radio otomatis berpindah lagu begitu lagu di Spotify Owner diganti atau dilewati.

### 2. 🔒 Penguncian Antrean Radio (Play Lock)
- **Fungsi:** Mengunci pemutar agar tidak diinterupsi oleh request lagu dari user lain saat sinkronisasi Spotify sedang berjalan.
- **Fitur:**
  - Seluruh command `.play`, `.fav`, atau playlist dari luar akan secara otomatis ditolak dengan pemberitahuan khusus.
  - Untuk mematikan kunci dan membuka kembali antrean bagi umum, Owner cukup mengetik `.stophearingme`.

### 3. 🚨 Notifikasi Error WhatsApp Langsung (Direct Error Alerts)
- **Fungsi:** Mengirimkan pesan peringatan atau crash error log bot secara langsung ke nomor WhatsApp Owner.
- **Fitur:**
  - Mencegah spam dengan sistem buffering dinamis (menggabungkan beberapa error dalam rentang 2 detik).
  - Membantu pemantauan server tanpa harus membuka terminal console panel hosting/Pterodactyl.

### 4. 📅 Laporan Rekap Radio Mingguan Otomatis & `.recapsubs`
- **Fungsi:** Mengubah fitur rekap radio bulanan menjadi mingguan (weekly) dan menambahkan sistem langganan grup otomatis.
- **Fitur:**
  - Command `.recap` sekarang menampilkan statistik dengerin radio mingguan (Minggu Ini & Minggu Lalu).
  - Command `.recapsubs` khusus Owner untuk mendaftarkan grup chat agar menerima siaran rekap otomatis.
  - Bot otomatis memancarkan laporan rekap mingguan setiap hari **Senin pukul 00:00 WIB** ke seluruh grup yang berlangganan.

## 📋 Command Summary

| Command | Aliases | Akses | Kegunaan |
|---|---|---|---|
| `.playowner` | `listensync`, `syncowner` | Owner | Menghubungkan radio dengan Spotify secara realtime & mengunci antrean |
| `.stophearingme` | `stopsync`, `unsyncowner` | Owner | Mematikan sinkronisasi Spotify & membuka kunci antrean radio |
| `.recapsubs` | `subrecap`, `langgananrekap` | Owner | Toggles langganan pengiriman laporan mingguan otomatis ke grup |
