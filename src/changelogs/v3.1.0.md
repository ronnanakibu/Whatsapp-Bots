# Release Notes v3.1.0 - Public Dashboard Summary & Landing Portal

This minor release introduces a completely separate, public-facing landing portal and ecosystem showcase page called **"Dashboard Summary"** for visitors, friends, and community members. It enables public system monitoring, live radio streaming, and developer storytelling without needing authentication.

## What's New

### 🏠 Public Summary Landing Page (Dashboard Summary)
- Created the new public landing view [PublicSummary.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/PublicSummary.tsx) at `/dashboard` index route.
- Designed a fixed floating navigation bar with shortcuts for Home, Features, Live Status, Radio, Developer, and Roadmap.
- Integrated a theme toggle with persistent state supporting Dark Mode (Calm Indigo) and Light Mode (Clean Slate).
- Implemented a Raycast-like command palette modal (`Ctrl + K`) for keyboard navigation, section search, and system commands.

### 📊 Real-Time Ecosystem Telemetry & Counters
- Added animated counters for Messages Processed, Commands Executed, AI Requests, Downloads, Active Groups, Active Users, and System Uptime.
- Visual elements are bound directly to the live Zustand state store synchronized via WebSocket events.

### 📻 Built-in Live Radio Audio Player
- Created a premium lo-fi vinyl mini-player containing album artwork, song titles, requesting user tags, and live listener count.
- Integrated HTML5 Audio streaming directly inside the dashboard with play/pause controls, muting options, volume sliders, and active visualizer bars.
- Provides fallback direct stream connection options to the root URL `/stream`.

### 🛡️ Live System Status Indicators
- Added a health monitoring block tracking Bot Core, WhatsApp Link, AI fallbacks, SQLite Database writes, Downloader status, and API health in real-time.

### 👨‍💻 Developer Timeline & Stories
- Created a premium story section detailing developer journey milestones from 2024 through 2026 and future plans.
- Integrated visual masonry project preview galleries with full-screen expansion drawers.
