# v5.7.4 — Low Quality Support for Anomaly Text Stickers

**Release Date:** 2026-06-22

## ✨ Fitur Baru & Peningkatan

### 1. 🎛️ Dukungan Degradasi Kualitas Rendah (Low Quality) pada Stiker Anomali / Brat — `--lq`
- **Fungsi:** Memperluas fitur kompresi pixelation/low quality (`--lq`) yang sebelumnya eksklusif pada stiker media (gambar/video) agar dapat diaplikasikan langsung pada stiker teks anomali (brat generator) melalui command `.anomali` (aliases: `.qs`, `.qc`, `.brat`).
- **Fitur:**
  - Melakukan pra-degradasi format JPEG/WebP cascaded compression dan pixel scaling pada output stiker teks brat secara proporsional.
  - Memotong string `--lq` secara aman dari parameter utama input sehingga stiker teks bersih dari flag parameter.
  - Mendukung input manual flag (contoh: `.qs --lq 90 hello world` atau reply chat dengan `.qs --lq 90`).
