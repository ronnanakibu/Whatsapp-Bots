# Changelog v5.14.18

## Bug Fixes
- **FFmpeg Blend Color Correction**: Fixed the deep purple tint issue affecting all generated videos by forcing FFmpeg's `blend` filter to operate in the `gbrp` (planar RGB) color space instead of the native YUV color space (which shifts neutral chroma planes directly into the magenta/purple range). Reconverted output to standard `yuv420p` post-blend for client compatibility.
- **Video Prompt Hardcoding**: Bypassed video motion prompt enhancement via LLMs (Gemini/Groq/NVIDIA) to use a high-quality hardcoded cinematography motion prompt optimized for LTX-Video.
