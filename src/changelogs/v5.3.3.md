# Changelog v5.3.3 — Android Gradle Build & Run NPM Scripts

## Features
- **NPM Scripts & Helper Script for Android Automation**:
  - Added custom NPM automation scripts in the root [package.json](file:///d:/CE/JavaScript/BOTS/WABOT2.0/package.json) to quickly compile, install, and launch the newly built Jetpack Compose Android client on physical/virtual devices.
  - Created a robust platform-agnostic automation runner in [scripts/android-helper.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/scripts/android-helper.js) that handles:
    - **Gradle Wrapper Validation**: Verifies that the Gradle wrapper (`gradlew.bat` or `gradlew`) has been successfully generated via Android Studio sync. If missing, it provides clear, step-by-step instructions to the user.
    - **Automatic ADB Path Resolution**: Detects if `adb` is missing from the system's `PATH` variable, and automatically searches in default Android SDK installation folders on Windows (`%LOCALAPPDATA%`), macOS, and Linux to run ADB commands successfully.
  - Commands added:
    - `npm run android:build`: Compiles the debug APK using Gradle (`assembleDebug`).
    - `npm run android:install`: Installs the compiled debug APK onto the connected Android device via ADB (`installDebug`).
    - `npm run android:run`: Automates the full build pipeline, installs the app, and triggers ADB to auto-launch the Android application's `MainActivity` (`com.ronnbot.radio/com.ronnbot.radio.MainActivity`) directly on the target device.
