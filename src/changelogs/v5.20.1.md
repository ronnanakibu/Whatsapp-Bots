# Release Notes v5.20.1

### 🔧 Perbaikan Deteksi & Pengiriman Prompt Media Sekali Lihat (View Once)
- **Deteksi Mendalam Bersarang (Deep Recursive Detection):**
  - Memperbaiki deteksi pesan sekali lihat (*View Once*) agar dapat menangkap pesan yang berada di dalam pembungkus pesan sementara (*disappearing messages / ephemeral chat*), `viewOnceMessage`, `viewOnceMessageV2`, dan `viewOnceMessageV2Extension`.
- **Pengunduhan Media Multi-Strategi:**
  - Mengimplementasikan 3 lapis strategi pengunduhan media WhatsApp untuk memastikan media dapat diunduh tanpa gagal.
- **Eksklusi Khusus Nomor Bot (Owner & Pengirim Lain Diikutsertakan Penuh):**
  - Memastikan pesan sekali lihat dari nomor Owner maupun pengirim/anggota grup mana pun tetap ditangkap dan dilaporkan ke Owner, hanya mengecualikan nomor bot itu sendiri.
- **Pengiriman Prompt Tanpa Blokir:**
  - Memastikan prompt konfirmasi interaktif ke Owner selalu dikirim secara instan meskipun pratinjau media sedang dalam proses pengunduhan di latar belakang.
