# Changelog v5.3.20

## 📝 Diagnostic Logs and Improved Rembg Error Tracking

This release adds self-diagnostic logging and improves logging visibility for background removal errors.

### Key Changes:

1. **Self-Diagnostic Boot Sequence (`start.js`)**
   - Added command line diagnostic queries on boot, writing key environment configurations and Python/Rembg installation details to `./storage/logs/diagnostic.log`.

2. **Improved Error Logging (`src/services/media.js`)**
   - Refactored `logger.error` statements in media processing functions to output full error structures to the Pino logger, allowing exact system tracebacks to be recorded in `app.log`.
