# v5.16.4 — Improved Downloader Error Accuracy & Database Fault Tolerance

## Bug Fixes
- **Improved Downloader Error Reporting**: Fixed an issue where downloader errors were incorrectly reported as generic connection timeouts on WhatsApp whenever a fallback API encountered a timeout, ensuring accurate and clear error messages and troubleshooting tips are presented.
- **Facebook Share Link Resolution**: Added automatic resolution for Facebook share links (e.g. `facebook.com/share/...`), redirecting them to their canonical video format before processing.
- **Database Fault Tolerance**: Wrapped background chat log archiver and database queries with graceful fallback handling to prevent unhandled database connection crashes when PostgreSQL is offline or unconfigured.
