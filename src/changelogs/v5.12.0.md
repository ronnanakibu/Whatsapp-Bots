# Changelog v5.12.0

## Dynamic Automation Workflow Diagram on Music Dashboard
- **Interactive Flowchart & Timeline Layout**: Refactored the `/music` dashboard status pipeline tracking section into a premium, responsive Automation Workflow Diagram.
  - **Desktop 2D Flowchart**: Renders a clean 2D layout showing the parallel stages, merge points, and active nodes of the generation engine utilizing SVGs and motion path markers.
  - **Mobile Vertical Timeline**: Automatically falls back to a sleek, compact timeline layout for small devices to maintain readability and performance.
- **Accurate Step Tracking**: Fully integrated the new Video Motion Background generation stage (`video_gen`) into the live pipeline socket status listener with custom progress estimation and log parsing.
- **Enriched Aesthetics**: Implemented premium ambient glows, glassmorphic cards, state colors (pending, running, completed, failed), and smooth micro-animations.
