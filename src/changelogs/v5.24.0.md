# v5.24.0 (Group Admin Privilege Integration for Message Deletion)

## Features
- **Group Admin Message Deletion Privilege**: The `.delete` command is now accessible to verified Group Admins as well as the bot Owner, enabling admins to maintain their group chats seamlessly.
- **Cross-Member Moderation Removal**: When invoked in a group where the bot has administrator privileges, both the Owner and Group Admins can delete problematic messages sent by any group participant for everyone.
- **Privilege Validation & Feedback**: Provides informative guidance when non-admin members invoke moderation commands or when the bot itself requires promotion to group administrator.
