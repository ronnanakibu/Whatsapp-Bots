# Changelog v5.3.12

## 🛠️ Native JWT Signing (Dependency Elimination)

This release resolves a bootstrap crash on Pterodactyl by removing the external `jsonwebtoken` library and signing JWTs natively.

### Key Changes:

1. **Native Crypto JWT Signing**
   - Replaced `jsonwebtoken` imports in `src/services/user-v2.js` with a custom HS256 JWT builder using Node's native `crypto` module.
   - Eliminates `ERR_MODULE_NOT_FOUND` errors on startup.
   - Aligns signature verification directly with the native signature verifier in WABOT2.0's Express app.
