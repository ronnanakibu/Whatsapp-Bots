# Changelog - v5.3.30

## [5.3.30] - 2026-06-17

### Changed
- **Reordered Instagram Downloader Priority:**
  - Promoted local `yt-dlp` to **Stage 1 (Primary)** inside the Instagram downloader pipeline (`src/services/downloader/providers/instagram.js`).
  - Set the new download fallback workflow to:
    1. **Stage 1:** Local `yt-dlp` (Paling update, stabil, bypasses CDN limits, runs via standalone Python).
    2. **Stage 2:** Embed Scrape (Direct HTML scraping).
    3. **Stage 3:** Third-party public APIs (SaveIG, SnapSave, InstaFinsta).
  - This ensures optimal download speeds and mitigates failures from third-party sites going offline or rate-limiting server IPs.
