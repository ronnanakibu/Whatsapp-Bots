# Changelog v5.3.7 — Dynamic Local yt-dlp Auto-Updater & Fallback

## Features & Bug Fixes
- **Prioritized Local yt-dlp Auto-Download**:
  - **Issue**: Relying on the hosting environment's system-wide `yt-dlp` executable (which was and remains extremely outdated on the Pterodactyl server) bypasses the auto-download mechanism. This triggers `Requested format is not available` on YouTube streams due to signature check drift.
  - **Fix**: Rebuilt the binary resolution logic in [ytdlp.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/services/ytdlp.js) to enforce downloading the latest official release from GitHub (`https://github.com/yt-dlp/yt-dlp`) directly to `./storage/bin/yt-dlp` on startup, instead of falling back to system-wide executables.
  - **Auto-Fallback**: If the GitHub downloader fails (e.g. network/DNS blockages), it falls back gracefully to checking the system `PATH` as a last resort.
  - **Cross-Platform Support**: Dynamic resolution of `.exe` suffix depending on platform (`win32` vs `linux`/`darwin`).
