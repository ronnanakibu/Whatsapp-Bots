# Changelog v5.3.18

## 📦 DNS Resolution Order Optimization (ETIMEDOUT Fix)

This release resolves intermittent `fetch failed` errors (caused by `ETIMEDOUT` in Node's underlying `undici` engine when connecting to WhatsApp CDN and Google API servers) by prioritizing IPv4 DNS lookup results.

### Key Changes:

1. **Prioritize IPv4 Resolution in Bot Process (`src/core/bot.js`)**
   - Imported Node's native `dns` module and configured `dns.setDefaultResultOrder('ipv4first')` at the very start of execution.
   - This prevents network timeouts caused by broken or misconfigured IPv6 routing interfaces on remote hosting servers (like Pterodactyl Alpine nodes), resulting in instant and reliable media downloads.

2. **Prioritize IPv4 Resolution in Bootstrap Process (`start.js`)**
   - Configured `dns.setDefaultResultOrder('ipv4first')` in the bootloader file to stabilize pre-launch downloads (fonts, ffmpeg, yt-dlp).
