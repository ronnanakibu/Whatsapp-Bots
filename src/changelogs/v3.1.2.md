# Release Notes v3.1.2 - Rebranding & CSS Mockups Update

This patch release rebrands "BotOS" to "RonnBot" across the dashboard panels to keep branding clear, refines the Developer Contact layout to avoid email overlaps, and introduces styled, mini CSS mockups for the ecosystem previews.

## What's New

### 🏷️ RonnBot Rebranding
- Swapped references of the brand "BotOS" with "RonnBot" across metadata headers, sidebar navigation components, setting titles, and descriptions.

### 🎨 Premium CSS UI Mockups
- Created styled, lightweight CSS mockups for the project previews to show exact details:
  - **RonnBot Control Panel**: Displays mini sync cards tracking active system telemetry (CPU, RAM, Uptime) and real-time logs.
  - **Database Inspector**: Displays simulated SQL workspaces executing query fields over active data tables.
  - **Command Registry**: Displays mock register listings with sliding toggle switch states.
- Replaced the simple static black preview boxes with these mockups. On mouse hover, the "Click to expand preview" overlay fades in.

### ✉️ Developer Details Alignment Fixes
- **Email Layout**: Wrapped the contact layout in responsive column flex containers (`flex-col sm:flex-row gap-1 sm:gap-0`) with truncation limits to prevent long email strings (`ronnsihombing2007@gmail.com`) from overlapping labels on smaller device viewports.
- **Instagram**: Pointed handle values and redirection URLs to the correct profile `@ronnlbtrn_`.
- **Creative Portfolio**: Updated values to "Coming Soon" and set link redirection to `#`.
