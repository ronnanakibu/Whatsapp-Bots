# Changelog - v5.3.28

## [5.3.28] - 2026-06-17

### Added
- **Dynamic Libc (Glibc/Musl) Standalone Python Resolution:**
  - Integrated a dynamic libc detection script using `ldd` and filesystem lookups to identify whether the host container is running Alpine Linux (`musl`) or a standard Debian/Ubuntu image (`glibc`/`gnu`).
  - Automatically queries and downloads the matching CPython standalone package from Python Build Standalone.
  - Resolves local C++ compilation dependency errors by pulling `gnu`-based standalone python on standard containers. This allows `pip` to match and download precompiled `manylinux` wheels for heavy dependencies (such as `numpy`, `onnxruntime`, and `rembg`), avoiding compilation entirely.
  - Implemented dynamic transition/marker validation (`libc_type.txt`) to automatically clean and switch Python standalone installations when the host environment libc configuration changes.
