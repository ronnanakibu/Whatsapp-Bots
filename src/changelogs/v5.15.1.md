# Release Changelog v5.15.1

## Interactive Subscribe Button & Metadata Improvements

- **Muted Subscribe Button Overlay**: Integrated transparent WebM Subscribe Button overlays into single-song video rendering and playlist video mix pipelines. The overlay appears automatically at three strategic timestamps (Middle, Random, and End) without interrupting the primary audio stream.
- **Resilient Fallback Handling**: Added a validation check that verifies overlay video path existence. If the button asset is missing, the render pipeline gracefully skips the overlay step without disrupting processing.
- **Clean Playlist Descriptions**: Omitted explicit Google Drive download URLs from the public YouTube playlist descriptions, optimizing description layouts and maintaining clean metadata presentation.
