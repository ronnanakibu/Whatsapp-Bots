# v5.24.1 (Meme Soundboard & Custom Voice Note Engine Overhaul)

## Features
- **Permanent Custom Sound Storage**: The `.sound add` / `.sound save` command now preserves audio buffers directly into persistent database storage as well as the private Cloud Vault, guaranteeing sounds remain intact even across server redeployments.
- **Robust Multi-Format Media Ingestion**: Custom sounds can now be saved by replying to Voice Notes, audio clips, documents, or video messages, leveraging pre-cached buffers and automated audio extraction.
- **Expanded Meme Soundboard Library**: Added an expanded collection of 26 verified classic and viral meme sound effects that stream directly with instant response times.
- **Intuitive Sound Management**: Added support for `.sound list`, `.sound del <keyword>`, and full Indonesian command aliases (`add`, `save`, `simpan`, `del`, `delete`, `hapus`, `list`, `daftar`).
