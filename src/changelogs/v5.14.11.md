# Changelog v5.14.11

## Bug Fixes
- **Gradio Client Authorization Key**: Changed the connection options key from `hf_token` (Python SDK) to `token` (JavaScript/Node SDK) in `suno.js`, `hf.js`, and `ai.js` to correctly pass authorization headers to private spaces.
- **Private Space ID Alignment**: Replaced the direct `.hf.space` subdomain URL of your custom space with the official case-sensitive Space ID (`ronnLbtrn/ronnbot-ltxvideo`) to allow the Gradio client to resolve space metadata using the authenticated session.
