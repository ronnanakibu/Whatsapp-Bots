# Release Notes v4.0.1 - Discord Radio Pipeline Fixes

This release addresses issues with YouTube cookies formatting for yt-dlp and resolves errors in the SoundCloud fallback pipeline.

## Bug Fixes

### 📻 Radio Service & Cookie Compatibility
- **Netscape Cookie Conversion**: Added a dynamic cookie converter that checks `youtube-cookies.json` and, if formatted as a JSON array (standard browser exporter format), automatically compiles and updates `youtube-cookies.txt` in the Netscape format expected by `yt-dlp`.
- **Netscape Cookie Header Parsing**: Enhanced `radio.js` cookie parser to support both JSON and Netscape cookie files, converting them into standard header strings for `play-dl` configuration.
- **YOUTUBE_COOKIE Env Support**: Added native `--add-header` support for `process.env.YOUTUBE_COOKIE` string in `yt-dlp` arguments.
- **Resilient SoundCloud Fallback**: Fixed the crash where the SoundCloud fallback threw `Cannot read properties of undefined (reading 'client_id')` when the client ID fetch failed or timed out. If the dynamic `getFreeClientID()` fails, the bot now falls back to a verified working default SoundCloud client ID (`Yks9HNwSpw5Bo7goMq3jv8cyDYgoLpZr`).
