# Changelog v5.14.0

## Suno Session Cookie Sync Integration
- **Cookie Sync POST Endpoint**: Added `/api/music/update-cookie` POST endpoint on Express backend (`radio.js`) to parse and persist Suno session cookies into `.env` configuration file automatically.
- **Suno Session Sync Card**: Rendered a premium settings panel under the left column of the `/music` dashboard.
- **Dynamic Javascript Bookmarklet**: Built a drag-and-drop Bookmarklet that detects the loaded bot host automatically, allowing users to login to Suno, solve captchas natively, and synchronize their clerk sessions instantly with one click.
- **Manual Cookie Sync Field**: Added a manual paste text field for copy-pasted document.cookie strings supporting mobile and fallback browsers.
