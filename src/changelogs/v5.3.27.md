# Changelog - v5.3.27

## [5.3.27] - 2026-06-17

### Fixed
- **Clean Local Pip Failure Interception:**
  - Resolved console error spam on boot when Python packages fail to compile (specifically `cmake` and `patchelf` requiring standard native C/C++ compilation tools like `gmake`, `make`, or `gcc` which are typically missing on minimal Pterodactyl Alpine containers).
  - Intercepted the verbose, multi-line compilation traceback in `start.js` and replaced it with a clean, descriptive warning alerting users of the lack of compiler tools and pointing to the automatic Remote API fallback (`KenjieDec/RemBG`).
