# Changelog - v5.11.0

## 🚀 Fitur Baru
- **Progress ETA & Persentase Rendering Video**: Proses rendering video pada dashboard kini menampilkan indikator persentase penyelesaian dan perkiraan sisa waktu (ETA) yang presisi secara real-time pada antarmuka log proses.
- **Koneksi Otomatis Status Dashboard**: Dashboard web kini secara dinamis terhubung langsung dengan proses yang berjalan di latar belakang. Ketika ada tugas baru yang dipicu lewat WhatsApp, halaman proses akan otomatis menampilkan logs dan visualisasi progress secara instan.
- **Pembaruan Engine Gambar & Upscaling Pintar**: Menambahkan tiga engine kecerdasan buatan baru yang premium untuk pembuatan gambar. Sistem kini secara otomatis memproses gambar pada resolusi optimal, lalu melakukan peningkatan resolusi berkualitas tinggi ke aspek rasio landscape 16:9 (1920x1080) menggunakan komposit berkecepatan tinggi.
- **Animasi Video Latar Belakang Otomatis (Image-to-Video)**: Mengintegrasikan modul kecerdasan buatan pembuat animasi video secara dinamis. Bot akan mendeteksi suasana lagu, menggerakkan objek gambar dasar, lalu secara mulus menggabungkan video bergerak tersebut secara berulang (looping) agar serasi dengan durasi penuh audio musik.
- **Teks Deskripsi Tanpa Batas**: Menghilangkan batasan jumlah kata (argumen) pada perintah WhatsApp, memungkinkan pengiriman prompt deskripsi musik yang sangat panjang tanpa terpotong oleh validator keamanan.

## 🎨 Pembaruan Desain & UI/UX
- **Desain Banner Poster pada Thumbnail**: Setiap thumbnail lagu yang diunggah ke YouTube kini secara otomatis dihiasi dengan banner gradien gelap modern pada bagian bawah, menyorot Judul Lagu dengan teks putih tebal beresolusi tinggi beserta sub-label estetis.
- **Tombol Salin Link di Koneksi HTTP**: Memperbaiki fungsi tombol "Copy" pada dashboard agar tetap berfungsi 100% dengan lancar meskipun pengguna mengakses dashboard melalui koneksi HTTP biasa (tanpa enkripsi HTTPS).

## 🛠️ Perbaikan Teknis & Backend
- **Pembaruan Otak Utama (Brain Model)**: Model Qwen 2.5 72B Instruct kini resmi dikonfigurasi sebagai otak pemrosesan utama untuk membalas obrolan bot secara default dengan menggunakan kunci API generasi terbaru.
