# Changelog - v5.17.0 (Anna's Archive Digital Library Integration)

Support for searching and downloading digital books, literature, and document files from Anna's Archive via the new `.annas` command.

## User-Facing Features

- **Anna's Archive Book Search & Downloader (`.annas`)**
  - **Search Mode (`.annas <judul/penulis>`)**: Instantly search for books by title or author and receive formatted top matches with title, author, language, format/extension, and file size.
  - **Direct Download (`.annas <link_annas | MD5>`)**: Download and receive book files (PDF, EPUB, MOBI, dsb.) directly in WhatsApp as document attachments (for files under 100MB).
  - **Fallback Mirror Link Provider**: Automatically provides clean download mirror options if the file exceeds messaging size limits or requires manual download.
