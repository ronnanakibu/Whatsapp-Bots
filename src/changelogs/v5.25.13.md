# v5.25.13 (Ultra-Low Memory Architecture & 512MB RAM Optimization)

## Features & Improvements
- **Ultra-Low Memory Architecture**: Unified process lifecycle to eliminate parent-child process duplication, freeing over 150MB of operating system RAM immediately upon boot.
- **Intelligent Heap Management & MemoryGuard**: Implemented strict heap threshold capping and proactive memory watchdog to ensure the application stays safely under memory limits with zero sudden terminations.
- **High-Performance Message Store**: Streamlined in-memory dialogue caching with direct on-demand database offloading, ensuring rock-solid stability even in dozens of high-traffic groups.
- **Bandwidth & Buffer Conservation**: Optimized background media archiving to focus strictly on lightweight assets, shifting large media processing to on-demand execution.
