# Changelog v5.15.0

## Playlist Batch Upload Mode

### Dashboard - Music Generation Panel
- **Playlist Tab Sub-Mode**: Introduced a new toggle inside Manual Mode to switch between single audio uploads and Playlist batch mode.
- **Concurrent Drag & Drop Audio Uploads**: Support for drag-and-drop or batch file selection to upload multiple MP3/WAV tracks simultaneously with active background progress tracking.
- **Per-Song Options Cards**: Individual configuration panels for each uploaded song, allowing you to customize:
  - Song Title (optional, auto-detected from metadata or filename if left empty).
  - Artwork source selection: System Decide (automated generation), AI Prompt (visual description), or custom file uploads (image/video).
- **Interactive Sequence Control**: Reorder files in the queue using simple Up/Down buttons, and delete tracks from the queue instantly.
- **Form Validation Warnings**: Clear warnings list if any track has missing fields (blocks compilation if neither title nor visual prompt is set).
- **YouTube Configuration**: Added global inputs at the bottom for Overall YouTube Playlist title, transition style, and automated chapter compilation with popular lofi/music tags.
- **Live Checklist Timeline**: Running playlist jobs render a clean vertical live timeline detailing initialization, artwork creation, FFmpeg crop rendering, transition cross-dissolve, and YouTube cloud publishing.
