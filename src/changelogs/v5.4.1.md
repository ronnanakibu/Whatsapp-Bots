# v5.4.1 — Owner Delete Command

**Release Date:** 2026-06-18

## ✨ New Feature

### `.delete` — Hapus Pesan Bot dari Grup
Command eksklusif owner untuk menghapus pesan bot dari dalam grup.

**Dua mode operasi:**

#### Mode 1 — Reply pesan bot → hapus 1 pesan
```
(reply ke pesan bot) .delete
```
Hanya pesan dari bot sendiri (`fromMe: true`) yang bisa dihapus.
Mencoba hapus pesan orang lain → ditolak dengan pesan error.

#### Mode 2 — Bulk delete N pesan terbaru
```
.delete --20    → hapus 20 pesan terbaru bot di grup ini
.delete --50    → hapus hingga 50 pesan (batas maksimum)
```
- Mengambil dari `store.messages[chatId]` (in-memory message store)
- Filter hanya pesan `fromMe === true`
- Throttle 250ms antar-delete untuk menghindari rate-limit WA
- Status message otomatis ikut terhapus setelah selesai
- Melaporkan summary: berhasil / gagal

## ⚙️ Technical Notes

- File: `src/commands/owner/delete.js`
- Permission: `owner` only
- Gunakan `sock.sendMessage(from, { delete: key })` (Baileys standar)
- Bulk max: 50 pesan (konstanta `MAX_BULK`)
- Aliases: `del`, `unsend`, `hapus`
- Bot JID detection handle format `@s.whatsapp.net` + LID (`:XX@` stripping)
