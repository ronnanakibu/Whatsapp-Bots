# Release Notes v4.0.4 - Real-time Context and Agentic Command Router

This release introduces native date/time awareness for the AI engines, implements an Agentic Routing system that parses natural language requests, and adds a keyword-based pre-router to ensure 100% reliable direct command routing.

## New Features

### 📅 Real-time Clock Integration (`ai.js`)
- **Dynamic Time & Date Injection**: Created a dynamic system prompt generator (`getDynamicSystemPrompt()`) that automatically appends the current day of the week, date, time (Asia/Jakarta timezone), and region details to system instructions for all active chat providers (Nvidia, Groq, Gemini).

### 🤖 Agentic Command Router & Pre-Router (`aiRouter.js`)
- **Keyword Pre-Router**: Checks incoming AI-bound messages (via `.q`, mentions, replies, or DMs) against specific command keywords/patterns (like `stiker`, `brat`, `cuaca`, `dl`, etc.) first. If matches are found (e.g. asking for a sticker while quoting an image), it routes directly to the command handler without calling the AI engine, ensuring speed and 100% execution reliability.
- **Natural Language Tool Routing**: Added an AI routing utility that intercepts AI outputs. If the AI determines that the user's intent is to run a bot command (such as making a sticker, downloading a video, checking the weather, verifying hoaxes, generating images, etc.), it returns a structured JSON payload which is parsed to execute that command automatically.
- **Seamless Integration**: Integrated both direct routing and AI routing into the `message` handler (for DMs, group mentions, and seamless replies) and the `!q` command.
