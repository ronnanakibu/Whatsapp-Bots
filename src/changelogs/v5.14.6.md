# Changelog v5.14.6

## Bug Fixes
- **Fix Double File Extensions on Documents**: Resolved an issue where WhatsApp appended `.mpeg` to `.mp3` document files (causing them to show up as `.mp3.mpeg`). Changed the mapped document MIME type dynamically to specific audio codecs (like `audio/mp3` or `audio/wav`) corresponding to the actual file extension instead of using the generic `audio/mpeg` default, preventing auto-renaming by WhatsApp.
