# v5.23.0

## Features & Improvements
- **HuggingFace Storage Migration**: Mengalihkan storage media lokal (avatar, banner) ke HuggingFace Dataset storage (`@huggingface/hub`) menggunakan `HF_TOKEN` untuk mengatasi limitasi 3GB pada *host server* (Pterodactyl).
- **Service hfStorage.js**: Implementasi service `hfStorage.js` baru untuk menangani fungsi `uploadMedia` file.
- **Pembersihan Bloatware**: Menghapus command bot spesifik yang sudah usang dan tidak terpakai (`hkbp.js`, `almanak.js`, `nyanyian.js`, `annas.js`) dari codebase untuk menghemat ukuran repository.
- **Storage Cleanup Enforcement**: Menegaskan *garbage collection* temporer pada operasi berat seperti FFmpeg video rendering & audio generation untuk menghindari akumulasi cache.
- **HF Log Stream Spam Fix**: Memperbaiki masalah reconnect loop pada hfLogsStreamer.js yang menyebabkan spam di file log dan memicu bloat di pp.log serta console.log.
- **Dashboard Excluded**: Mengabaikan folder dashboard dan src/app/dashboard pada proses deployment SFTP untuk mencegah error ENOSPC pada Pterodactyl server.
