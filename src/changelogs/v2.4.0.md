# v2.4.0 (4 Juni 2026) — Auto AI Moderator & Anti-Toxic Group System

### 🚀 Update & Peningkatan:
- **Fitur Auto AI Moderator & Anti-Toxic**: Menambahkan pengawas grup berbasis kecerdasan buatan untuk menjaga ketertiban grup dari kata-kata kotor/makian, promosi judi/scam, dan ujaran kebencian.
  - **Evaluasi Groq**: Memanfaatkan model berlatensi rendah `llama-3.1-8b-instant` via Groq API dengan output format JSON murni untuk kecepatan dan konsistensi deteksi yang tinggi.
  - **Tindakan Otomatis (Auto Delete & Warn/Kick)**: Pesan toxic yang terdeteksi akan langsung dihapus otomatis oleh bot. Anggota akan diberi peringatan, dan jika batas maksimum terlampaui (default 3x), bot akan mengeluarkan (kick) anggota tersebut (jika bot berstatus admin grup).
  - **Pengecualian Khusus (Bypass)**: Admin grup dan Owner bot dikecualikan dari moderasi secara otomatis untuk mencegah false positive.
  - **Penyimpanan SQLite**: Batas peringatan per grup dan riwayat akumulasi peringatan anggota disimpan di tabel database lokal `moderation_config` dan `moderation_warnings`.
- **Perintah Baru `.aimod`**: Menambahkan perintah manajemen moderasi untuk grup admin (bisa mengetik `!aimod on/off`, `!aimod max [1-10]`, `!aimod warnings`, dan `!aimod reset @user`).
