# Changelog v5.2.0 — AI Overhaul, Vision Integration, yt-dlp Bypass & Favorites Lookup Mentions

## Features
- **AI Vision Integration in Chat**:
  - Automatically routes `.q` queries, seamless replies, mentions, and DMs containing direct or quoted images to Gemini Vision analysis.
  - Generates natural-language image analysis descriptions and stores them directly into the conversation history, allowing users to ask follow-up questions referencing the visual context.
- **Favorites Lookup via Mentions**:
  - Enhanced `.fav`, `.myfav`, and `.favlist` to support looking up other users' favorite lists by tagging them or typing their number (e.g. `.fav @mention` or `.myfav @mention`).
  - Implemented automatic highlight tagging in the lookup headers for a more premium visual experience on WhatsApp.

## Bug Fixes & Refactoring
- **AI Memory Retrieval Sequence**:
  - Fixed SQL query sequencing in `src/services/memory.js` where `getHistory` was pulling the oldest messages instead of the newest ones, resolving severe AI logical regressions and memory loss.
- **AI History JSON Command Pollution**:
  - Centralized memory history writing in `src/services/ai.js`.
  - Added a sanitation filter (`cleanMemoryMessage`) to convert raw JSON command strings into clean, descriptive action tags (e.g., `[Mengaktifkan fitur sticker]`) in the database, preventing the AI from generating JSON text on subsequent turns.
- **Isolated Utility Context Isolation**:
  - Blocked utility processes (such as `.summarize` and code debugger `debugCode` whose JIDs start with `__`) from reading or writing context to the user database.
- **Dynamic Mention Processing**:
  - Dynamically extracts message `contextInfo` for Baileys depending on the incoming payload type (`imageMessage`, `videoMessage`, etc.), fixing missing group mentions in image/video captions.
- **yt-dlp Extractor Arguments**:
  - Appended `['--extractor-args', 'youtube:player_client=android,web']` to the yt-dlp spawn arguments to bypass strict YouTube server IP blockages.
- **FFmpeg Piping Audio Lag**:
  - Added the `afifo` (audio FIFO buffer) filter graph in the streaming stream track pipeline, eliminating live broadcast audio stuttering and buffering delay.
- **Rembg CLI Graceful Error Handling**:
  - Modified background removal executions to invoke `python -m rembg` (more stable than global PATH commands on container hosts).
  - Added error catchers that intercept module-not-found failures and direct users to run `pip install rembg` to enable background removal.
