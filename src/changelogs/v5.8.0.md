# v5.8.0 — Emoji Sticker Layout, PDF Utility Suite, Video/Audio Editor & Sound from Video

**Release Date:** 2026-06-30

## 🛠️ Pembaruan Layout Stiker & Modul Utilitas Dokumen / Media

Rilis ini menghadirkan perbaikan tata letak emoji pada stiker agar presisi, meluncurkan suite pengelolaan dokumen PDF lengkap, fitur penggabungan video/foto dengan audio, serta kemampuan ekstraksi suara langsung dari video.

### Fitur Baru & Peningkatan:

- **Presisi Emoji Stiker (Inline Layout)**:
  - Emoji di dalam teks stiker (baik stiker meme biasa, animasi, maupun stiker teks brat/anomali) sekarang dirender secara inline mengikuti posisi teks asli dan diposisikan dengan benar di bagian tengah (centered) untuk mencegah pergeseran atau teks tumpang tindih.
  - Ditambahkan mekanisme fallback aman yang otomatis merender emoji sebagai teks standar jika terjadi kendala unduhan pada aset gambar.

- **Suite Dokumen PDF (`.pdf`)**:
  - **Merge PDF (`.mergepdf`)**: Menggabungkan beberapa dokumen PDF dari riwayat chat secara berurutan.
  - **Split PDF (`.splitpdf`)**: Memotong dan mengambil rentang halaman tertentu dari file PDF.
  - **Image to PDF (`.img2pdf`)**: Mengonversi gambar di chat menjadi satu berkas PDF siap cetak.
  - **PDF to Image (`.pdf2img`)**: Mengubah dokumen PDF menjadi rangkaian gambar halaman demi halaman dengan format PNG.
  - **Word to PDF (`.doc2pdf`)**: Mengonversi berkas dokumen Word (.docx) menjadi file PDF menggunakan rendering web.
  - **Compress PDF (`.compresspdf`)**: Mengoptimalkan ukuran berkas PDF untuk menghemat kuota dan mempermudah pengiriman.

- **Editor Penggabungan Media HD (`.editing`)**:
  - Menyatukan video bisu atau foto statis dengan file audio/VN dari chat menjadi sebuah video MP4 HD yang utuh.
  - Mampu mencari dan mencocokkan media pendukung dari riwayat obrolan secara otomatis jika salah satu file tidak disertakan.

- **Ekstrak Audio Video (`.sound add`)**:
  - Perekaman VN lokal baru kini dapat dilakukan langsung dengan mereply video. Bot akan mengekstrak aliran audio secara otomatis dan menyimpannya sebagai sound lokal di dalam basis data.
