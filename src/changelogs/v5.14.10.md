# Changelog v5.14.10

## Feature Enhancements
- **Custom LTX-Video Space Integration**: Added the user's custom Hugging Face Space (`RonnBot Own LTX-Video`) as the primary candidate (#1) in the video generation fallback list, configured with precise duration (`73` frames / ~3 seconds @ 24fps) and step counts.
- **Dedicated LTX-Video Prompt Enhancer**: Implemented a specialized `enhanceVideoPrompt(rawPrompt)` function that uses LLMs (Gemini/Groq/NVIDIA) to automatically transform user input into structured, detailed, and motion-rich visual prompts tailored to LTX-Video best practices.
- **Groq Models Cleanup**: Removed the deprecated `mixtral-8x7b-32768` model from the `GROQ_MODELS` list to optimize response times and prevent unnecessary model-rotation retries.
