# v5.4.0 — Multi-Source Sound + VN Save Feature

**Release Date:** 2026-06-17

## 🎵 New Features

### Sound Command — Multi-Source Search
The `.sound` command now searches across **3 online sources** in priority order before giving up:

1. **iMyFone Soundboard** (`filme.imyfone.com`) — via reverse-engineered JSON API `voxbox-voice-ma-api.imyfone.com`
2. **SoundButtonsWorld** (`soundbuttonsworld.com`) — via internal Angular API `/api/memes/search?page=0&pageSize=5&q=...`
3. **MyInstants** (existing fallback) — via HTML scraping

This massively expands the sound library from hundreds to **millions** of meme sounds.

### VN Save Feature — `.sound add <nama>`
Users can now save their own Voice Notes (VN) directly to the bot database:
- **Reply to any audio/VN**, then type: `.sound add <keyword>`
- The audio is downloaded and stored locally in `./storage/sounds/`
- Saved VNs are played back as PTT (push-to-talk) messages

### VN Delete — `.sound del <nama>`
- Removes a saved VN from the database and deletes the audio file
- Also works for removing URL-cached sounds

### Source Tracking
- The `sound_cache` SQLite table now includes a `source` column (`imyfone`, `soundbuttonsworld`, `myinstants`)
- The list view (`.sound` with no args) shows source labels and separates VN from URL-cached sounds

## 🛠️ Technical Changes

### `src/commands/entertainments/sound.js`
- Added `scrapeImyfone(query)` helper — iMyFone JSON API
- Added `scrapeSoundButtonsWorld(query)` helper — SBW internal API
- Added `sound_vn` SQLite table for local VN file storage
- Added `add` and `del` sub-commands with proper quoted-message audio detection
- Auto-creates `./storage/sounds/` directory on first use
- DB schema migration: `sound_cache.source` column added (`DEFAULT 'unknown'`)
- `downloadMediaMessage` from Baileys used for VN download
- Improved list view with separate sections for Built-in / VN / Cached sounds

## 📋 Usage

```
.sound bruh              — kirim sound bruh
.sound bing chilling     — cari di iMyFone → SBW → MyInstants
(reply VN) .sound add rizz  — simpan VN dengan nama "rizz"
.sound rizz              — putar VN yang tersimpan
.sound del rizz          — hapus VN "rizz"
.sound                   — tampilkan semua sound tersedia
```
