# v5.16.0 — Motion Thumbnails, Vignette Mode & Description Field

## New Features

### 📝 Optional Description Field — Manual Song Upload (Single & Playlist)
- Added a **Description (Optional)** textarea to the **Single Song** manual upload form (appears after the Song Title field).
- Added a **Description (Optional)** textarea to **each individual song card** in the Playlist batch mode.
- If filled, the description is used directly as the YouTube video description instead of the auto-generated one.
- If both a user description and AI-generated metadata description are present, the user description is **prepended** to the AI description.
- For Playlist mode, each song's description appears inline in the YouTube description's tracklist timestamps (e.g. `00:00 - Song Title | Your description here`).

## New Features

### 🎥 Motion Thumbnails Toggle (LTX) — Playlist Mode
- Added a **"Motion Thumbnails (LTX)"** toggle in the Playlist settings section of the Suno Automation dashboard.
- When enabled, each song's static AI-generated artwork is automatically animated using the LTX Video generation pipeline before being merged into the final playlist video.
- Generation runs **sequentially** per track (not in parallel) to maximize queue stability.
- Full **graceful fallback chain**: if the primary LTX Space hits a quota limit, the pipeline automatically retries the next available Space. If all Spaces are exhausted, it gracefully falls back to the original static image artwork without interrupting the playlist.

### 🎭 Vignette Mode Selector
- Added a **3-way "Vignette Mode"** selector in the main generation form, visible for both single-song and playlist modes.
- **Normal** — No vignette effect applied (default).
- **Dark** — Applies a dark black border vignette (`vignette=color=black:angle=0.5`) for an epic/cinematic look.
- **Light** — Applies a soft white border vignette for a clean/bright aesthetic.
- The selected mode is injected directly into the FFmpeg filter complex chain for all video background render paths (motion background, static thumbnail, with/without particle overlay).

## Technical Notes
- `startSunoPipeline` and `startPlaylistPipeline` both accept the new `vignetteMode` parameter.
- `startPlaylistPipeline` accepts the new `generateMotion` boolean parameter.
- Both socket handlers in `radio.js` (`suno:generate`, `suno:playlist_generate`) now extract and forward these parameters from the frontend payload.
