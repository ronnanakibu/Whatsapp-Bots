# Version 5.17.2 Release Notes

## 🚀 Enhancements & Fixes

- **Instagram Downloader Stabilization**:
  - Resolved timeout errors (`Timeout 15000ms`) during Instagram Reels/Posts media downloads by purging dead third-party scraper endpoints and reducing fallback latency to 6 seconds per provider.
  - Added full support for double-escaped, single-escaped, and metadata embed video scrapers alongside automated JavaScript deobfuscation for public downloaders.

- **Optimized Fast Startup & Resource Efficiency**:
  - Streamlined the Pterodactyl bootstrap process by removing blocking child processes (such as automated Python background removal compilation and redundant diagnostic commands).
  - Ensured OpenSSL helper CLI generation and Prisma client generation run reliably on Pterodactyl container boot, resolving musl engine binding compatibility issues.
  - Background image processing smoothly uses local or high-speed Remote AI acceleration as needed without slowing down bot initialization.

- **Pterodactyl Local Timezone Update**:
  - Configured the system process timezone to `Asia/Jakarta` (WIB / GMT+7) across all Pterodactyl server logs and application execution contexts.
