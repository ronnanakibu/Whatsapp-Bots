# Release Notes v4.0.3 - Sticker Command Fixes

This release resolves crashes and media download failures in the sticker creation command.

## Bug Fixes

### 🎨 Sticker Command (`sticker.js`)
- **Missing Socket Variable**: Fixed a `ReferenceError: sock is not defined` crash by properly destructuring the `sock` instance from the command context (`ctx`).
- **Quoted Message Media Downloads**: Corrected how quoted media targets are parsed and constructed for `@whiskeysockets/baileys`' `downloadMediaMessage`. The target message now uses the unwrapped inner message (`finalQuotedMsg`) and correct key fields reconstructed from the metadata of the message being quoted.
- **Media Reupload Handler**: Integrated `reuploadRequest: sock.updateMediaMessage` into the media download process so that expired or stale media URLs from WhatsApp servers can be successfully re-uploaded and processed.
