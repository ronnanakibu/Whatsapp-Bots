# Changelog v5.3.22

## 🛡️ Boot Protection and Diagnostics Prioritization

This release ensures boot diagnostics run immediately on startup and any bootloader exceptions are caught and logged.

### Key Changes:

1. **Prioritized Diagnostics Block (`start.js`)**
   - Moved the diagnostics script to the very beginning of the `main()` function, immediately after directories are created, so that diagnostics are recorded even if subsequent setup functions crash.

2. **Boot Exception Catcher (`start.js`)**
   - Wrapped the entire bootstrap sequence in a global try-catch block that writes fatal setup errors and stack traces to `./storage/logs/boot_crash.log` before terminating, allowing headless diagnostics of container crashes.
