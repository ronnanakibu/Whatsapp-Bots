# Changelog v2.8.0

## What's New & Updates

### 🌐 ronn.ai Mission Control & Radio Hub
- **Layar Publik**:
  - **Radio Hub**: Siaran langsung 24/7 dengan 64-bar visualizer dinamis, progress tracker siaran live, form request lagu sinkron dengan perintah bot `.play`, serta tampilan antrean lagu dan riwayat baru diputar.
  - **Command Catalog**: Katalog 108 perintah lengkap dengan fitur spotlight search (shortcut global `Ctrl+K`), filter kategori chips, badge izin akses (Public, Admin Grup, Master Owner), dan tombol salin 1-klik.
- **Layar Owner (Mission Control)**:
  - **Autentikasi & Route Guarding**: Dilengkapi login Master Key/PIN owner sehingga halaman manajemen grup, sistem, dan terminal aman dari akses publik.
  - **Manajemen Grup**: Kendali fitur per-grup untuk AI auto-chat, anti-link WhatsApp, anti-toxic filter, broadcast pesan ke grup, serta proteksi keamanan leave grup.
  - **System Telemetry**: Monitoring status WhatsApp Baileys, penggunaan memori (RSS & Heap), disk, swap, grafik CPU dinamis, metrik routing model AI 3-tier, serta trigger sinkronisasi data cloud.
  - **Terminal Console**: Live stream stdout/stderr dengan filter level pesan (`INFO`, `WARN`, `ERROR`, `AI-ROUTER`), opsi jeda log, dan grafik ringkasan pesan per jam.

### 🤖 Bot Core & AI Routing
- **Stabilisasi Reasoning AI**: Mengoptimalkan interval edit pesan loading reasoning menjadi 5 detik untuk mencegah rate-limit dan glitching pada aplikasi WhatsApp.
- **Formatting Markdown**: Konversi otomatis format teks AI (`**bold**` dan `# Header`) menjadi format native WhatsApp (`*bold*`).
