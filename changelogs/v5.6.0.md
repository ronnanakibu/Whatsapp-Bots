# v5.6.0 — Sound Fix + HKBP Features (Almanak & Nyanyian)

**Release Date:** 2026-06-18

## 🐛 Bug Fix — `.sound add` VN Gagal Tersimpan

### Root Cause
`downloadMediaMessage()` di `sound.js` dipanggil **tanpa `reuploadRequest`** — Baileys membutuhkan `sock.updateMediaMessage` untuk bisa redownload media dari server WA (terutama untuk quoted message). Tanpa ini, buffer selalu kosong atau throw error.

Bugs tambahan:
- `fromMe` tidak dideteksi dengan benar di quoted message key
- WRAPPER types tidak semua di-handle dengan benar

### Fix
- Lazy import `downloadMediaMessage` dengan `{ logger, reuploadRequest: sock.updateMediaMessage }`
- Proper `fromMe` detection menggunakan `sock.user?.id` dan `sock.user?.lid`
- Handle semua wrapper types: `ephemeralMessage`, `viewOnceMessage`, `viewOnceMessageV2`
- Error message lebih informatif
