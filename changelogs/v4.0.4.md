# Release Notes v4.0.4 - Real-time Context and Agentic Command Router

This release introduces native date/time awareness for the AI engines and implements an Agentic Routing system that parses natural language requests and runs the appropriate bot commands automatically.

## New Features

### 📅 Real-time Clock Integration (`ai.js`)
- **Dynamic Time & Date Injection**: Created a dynamic system prompt generator (`getDynamicSystemPrompt()`) that automatically appends the current day of the week, date, time (Asia/Jakarta timezone), and region details to system instructions for all active chat providers (Nvidia, Groq, Gemini).

### 🤖 Agentic Command Router (`aiRouter.js`)
- **Natural Language Tool Routing**: Added a new AI routing utility that intercepts AI outputs. If the AI determines that the user's intent is to run a bot command (such as making a sticker, downloading a video, checking the weather, verifying hoaxes, generating images, etc.), it returns a structured JSON payload which is parsed to execute that command automatically.
- **Seamless Integration**: Integrated the agent router directly into the `message` handler (Routes 2, 3, 4) and the direct `!q` command.
