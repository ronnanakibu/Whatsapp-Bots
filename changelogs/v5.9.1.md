# WABOT2.0 Changelog

## v5.9.1
**Date:** 2026-07-03

### Features
*   **Suno API Integration:** Fully integrated `sunoapi.org` REST API for music generation.

### Fixes
*   **Suno Automation:** Bypassed Suno AI's Cloudflare Turnstile CAPTCHA limitations by migrating away from the unstable Playwright-based Vercel endpoint towards a managed API service (`sunoapi.org`).
*   **Server Compatibility:** Ensured the Suno integration works natively in restrictive environments (e.g., Alpine Linux on Pterodactyl panels) without requiring headless Chromium installations.
