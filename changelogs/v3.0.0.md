# Release Notes v3.0.0 - Major Features & Client Telemetry Update

This major release resolves state discrepancies on the dashboard client, introduces live AI/Moderation control toggles, reconstructs the AI Center with interactive telemetry logs, and replaces XP Level with actual Command Execution Counts.

## What's New

### 🔌 Global Singleton WebSocket Client
- Reimplemented `useSocket.ts` to utilize a single global WebSocket instance. This eliminates the multi-instance socket leakage bug that caused the dashboard to display "Offline" and "Socket Disconnected" when navigating between tabs, while maintaining full Socket connectivity in the background.

### 👥 User Directory & Command Usage Sorting
- Replaced the placeholder "XP Level" with a real "Used Commands" count sorted from highest to lowest usage.
- Integrated automatic user profile recording directly into the message handler (`src/handlers/message.js`). The bot now records user pushnames and increments their execution count in the SQLite database every time they run a command, completely solving the bug where group JIDs were listed as users.

### 🤖 Live AI Chat & AI Moderation Toggles
- Programmed real-time socket events `group:toggle_ai` and `group:toggle_moderation` inside `radio.js`. Toggling AI or Moderation in the dashboard now persists the settings to the database and propagates changes instantly without restarting the bot process.

### 📊 Reconstructed AI Center Telemetry
- Enriched the backend AI payloads to feed real-time latency pings, healthy/unhealthy status indicators, and model names.
- Redesigned `AICenter.tsx` to include custom SVG branding logos for Groq, NVIDIA, and Gemini.
- Added an interactive details inspection drawer: clicking any AI provider card now opens a details card showing hourly ping stability, cost estimation rates, accuracy rates, fallback ranking priorities, and specific engine model capabilities.

### 📦 Major Release Versioning
- Upgraded the package version of both the core bot and dashboard to `v3.0.0` in `package.json`, `src/app/dashboard/package.json`, and `Sidebar.tsx`.
