# WABOT2.0 - v5.23.1

## Fitur Baru & Peningkatan
- Menambahkan kapabilitas kategorisasi story otomatis: sekarang admin dapat menyetel kategori default untuk fitur sinkronisasi IG story melalui command .setkategori [nama_kategori].
- Bot sekarang membaca target kategori dinamis di storage/story_category.json untuk semua upload story otomatis.
- Menambahkan informasi label kategori dalam notifikasi push WhatsApp (serta command cara mengganti kategorinya) saat story berhasil diarsipkan.

## Perbaikan
- Menyelesaikan masalah _spam bootloop upload_ dengan mencegah unggahan ganda akibat story id yang identik dari spammer Instagram. (Cleaned up 360+ spam stories dari API).
