# Changelog v5.3.1 — Interactive Help & Categorized Menu Overhaul

## Features
- **Interactive Help & Categorized Menu**:
  - Redesigned the main `.help` / `.menu` / `.h` command to render a beautiful dashboard containing:
    - Bot runtime calculated dynamically using `process.uptime()`.
    - Total unique users resolved dynamically from the WhatsApp groups participation cache, with DB query fallback.
    - Version number parsed directly from `package.json`.
    - Active radio web dashboard URL.
    - Interactive Main Menu category index.
  - Registered individual category command aliases such as `aimenu`, `downloadmenu`, `toolsmenu`, `ownermenu`, `audiomenu`, `imagemenu`, `adminmenu`, and `generalmenu`.
  - Allowed both direct submenu trigger commands (e.g. `.aimenu`) and subcategory queries (e.g. `.help ai`) to render dedicated command sub-lists with their respective names and descriptions.
  - Implemented background pre-fetching and caching for WhatsApp group participating members count to eliminate API response delays.
