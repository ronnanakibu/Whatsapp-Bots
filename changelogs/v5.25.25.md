# v5.25.25 (Modern Dark Terminal Logs & Integrated Pairing Workflow)

### Features & Improvements
- **Interactive Dark Terminal Log Viewer**: Upgraded `/app.log` and `/api/system/app.log` from raw text dumps into an ultra-modern, eye-friendly Dark Mode web terminal. Features live non-blocking background streaming (auto-refresh), instant client-side keyword search, color-coded log levels (System, Warning, Error, Pairing), auto-scroll to bottom, 1-click clipboard copy, and raw log download.
- **Seamless Pairing Code Shortcut**: Added a direct 1-click portal link inside the log viewer header to immediately jump to the WhatsApp Pairing Code screen (`/pairing`), making linking fast and frictionless.
- **Single-Turn Authentication Transition**: Established automatic persistent snapshotting for freshly authorized WhatsApp sessions, ensuring the bot stays authenticated across cloud restarts and updates without recurring login prompts.
