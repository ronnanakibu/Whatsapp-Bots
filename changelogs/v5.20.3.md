# Release Notes v5.20.3

### 📊 Real-Time Terminal Console Logging
- **Visualisasi Penuh di Konsol Server / Pterodactyl:**
  - Mengaktifkan dan menyempurnakan logging konsol real-time untuk setiap aktivitas bot:
    - 📩 Pesan Masuk (DM / Grup, Tipe Media, dan Cuplikan Isi Teks).
    - 👁️ Intersepsi & Ekstraksi Pesan Sekali Lihat (View Once).
    - 💾 Pengunduhan dan Pre-caching Media ke Storage.
    - 📤 Pengiriman Prompt Interaktif ke Nomor Owner.
    - ✨ Pendaftaran dan Penyelesaian Sesi Interaktif SQLite.
    - 🕵️‍♂️ Deteksi Pesan Terhapus (Anti-Delete) & Pesan Diedit (Anti-Edit).
  - Menambahkan modul warna terminal ANSI untuk modul `viewonce`, `mediacache`, `interactive`, `revoke`, `edit`, dan `store`.
