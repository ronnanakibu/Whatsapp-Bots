# v5.23.7 (Sticker Vault Archiving, View Once Command, & Strict AI Scope Update)

## Features
- **Dedicated View Once Revealer Command (`.viewonce`)**: Added a direct command (`.viewonce`, `.rvo`, `.buka`) to reveal and resend view-once media without restrictions while synchronizing it to the Cloud Vault.
- **Realtime Sticker Input & Output Vault Archiving**: Generating stickers via `.s` now automatically archives both the user's raw source media and the bot's generated sticker into the private Cloud Vault in real time.
- **Direct Message Unquoted Confirmation Support**: Interactive decision prompts (such as restoring deleted messages or handling view-once media) can now be confirmed directly in private chat without needing to quote the alert.
- **Direct Message Support for `.delete`**: Expanded the owner `.delete` command to allow single-message and bulk message deletion inside private direct messages.

## Fixes
- **Automatic AI Interception Prevention**: Disabled unsolicited autonomous conversational AI triggers in private direct chats, ensuring the AI engine only activates on explicit commands (`.ai`, `.q`) or direct quoted replies to previous AI discussions.
