# Release Notes v3.1.5 - Horizontal Command Menu Refactor & Git Clean

This patch release refactors the bot's WhatsApp menu layout to be more compact, includes the direct web dashboard link at the top of the menu, and performs a complete Git repository cleanup to ignore build outputs.

## What's New

### 📱 Modern Horizontal Command Menu
- **Dashboard Link Integration**: Embedded the public dashboard URL at the very top of the `.help` / `.menu` command reply message.
- **Horizontal Grouping**: Overhauled [help.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/commands/general/help.js) category listings to output commands horizontally (`*🤖 AI*\n└─ \`!ai\`  \`!nvidia\`  \`!groq\``) rather than a long, scrolling vertical list.
- **Aesthetic Refactor**: Removed outdated vertical ASCII framing box decorations (`╭━━━`, `┃`, `╰━━━`) for both category headers and single-command detail summaries.
- **Rebranding in Info Commands**: Updated [aboutbots.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/commands/general/aboutbots.js) to rebrand "BotOS Dashboard" references to "RonnBot Dashboard".

### 📦 Source Control & Workspace Tree Clean
- **Ignored Next.js Build Outputs**: Added `src/app/dashboard/.next/` and `src/app/dashboard/out/` folders to the root [.gitignore](file:///d:/CE/JavaScript/BOTS/WABOT2.0/.gitignore).
- **Git Cache Prune**: Cleaned untracked files by untracking build folders from Git index cache (`git rm -r --cached`), reducing source control pending modifications down to zero.
- **Version Bump**: Bumped app specifications key values to `3.1.5`.
