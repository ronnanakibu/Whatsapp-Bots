# Changelog - v5.3.29

## [5.3.29] - 2026-06-17

### Added
- **Instagram Local yt-dlp Fallback:**
  - Integrated local `yt-dlp` execution as the final, ultimate fallback pipeline for Instagram content downloads (`src/services/downloader/providers/instagram.js`).
  - Ensures that if the embed scraper and all third-party public API scrapers (SaveIG, SnapSave, InstaFinsta) fail due to transient network drops, rate limits, or DNS timeout errors (`getaddrinfo EAI_AGAIN`), the bot will rescue the request by executing the local `yt-dlp` downloader running via the standalone Python engine.
