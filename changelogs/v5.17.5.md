# Version 5.17.5 Release Notes

## 🚀 Enhancements & Features

- **Automated JSON Cookie Converter & Integration**:
  - Added an automated JSON-to-Netscape cookie converter function in the bootstrap system.
  - Automatically formats raw browser JSON cookies into `./storage/cookies.txt` for `yt-dlp` authentication, enabling direct high-speed Instagram Reel and Post downloads.
