# v5.25.2 (Persistent Cloud Session Vault & Automated Login Preservation)

## Features & Improvements
- **Instant Session Vaulting on Connection**: WhatsApp authentication states are now immediately packaged and safely committed to cloud storage the moment the bot logs in, ensuring zero risk of unpreserved credentials during rapid cloud restarts.
- **Enhanced Cloud Storage Adapter**: Refactored the cloud archival layer with native binary blob packing, resolving transmission bottlenecks and guaranteeing persistent credentials retention across container redeployments.
- **Zero-Friction Authentication**: Re-deploying or restarting instances will now consistently pull existing valid credentials, eliminating repeated QR scanning prompts.
