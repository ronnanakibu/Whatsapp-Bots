# Changelog v5.3.24

## 🚀 Hybrid local/remote Rembg architecture to circumvent Pterodactyl Disk Limitations

This release introduces an elegant hybrid architecture for background removal, offering a remote Gradio/Hugging Face space fallback to prevent bot failures on memory/disk-constrained server packages.

### Key Changes:

1. **Hybrid Rembg Fallback (`src/services/media.js`)**
   - Refactored `MediaService.#executeRembg` to fall back to the Hugging Face `KenjieDec/RemBG` API space when the local Python script execution fails due to disk/memory OOM or environment limitations.
   - Refactored animated sticker frame background removal to dynamically chunk frame processing concurrently in batches of 5 over the remote API when local processing fails.

2. **Mitigate OSError 28 (No space left on device)**
   - Resolves the issue where low-resource Pterodactyl hosting packages fail to compile scipy/numpy/onnxruntime from source due to restricted storage space, by shifting processing to Hugging Face serverless spaces.
