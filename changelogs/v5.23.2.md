# v5.23.2 (Admin Console Redesign)

## Features
- **Admin Console Dashboard**: Completely redesigned the dashboard to follow a cPanel-style Bento Grid layout, providing immediate access to all subsystems (Messages, Analytics, AI Center, Groups, Users, Commands, Downloads, Moderation, Memory, Automations, Logs, Deployments, Developer, Settings).
- **OLED Dark Mode Theme**: Implemented OLED Dark Mode utilizing Deep Slate (`#020617`) and Neon Green (`#22C55E`) for a premium, developer-friendly appearance.
- **Top Navigation Bar**: Replaced the sidebar with a global Top Navigation Bar, adding real-time Bot Engine connection status indicators and global UI access.
- **Dynamic Asset Routing**: Enabled `basePath` configurations (`/dashboard` and `/radio`) across all Next.js applications to ensure static files are appropriately served through the Express.js HTTP backend.
- **Docker Build Optimization**: Restructured the `Dockerfile` to concurrently compile both the primary Admin Console and the Radio Dashboard, resolving critical `react-three/drei` and `react-spring` peer dependency conflicts during the CI build process using `--legacy-peer-deps`.

## Fixes
- **Module Dependency Crash**: Resolved `ReferenceError: require is not defined` inside `src/services/storySync.js` by transitioning legacy `require('crypto')` usage to an ESM-compatible dynamic import.
