# Changelog v5.3.15

## 📦 Log Optimization: Filter Out Standard Incoming Messages

This release filters out regular incoming text messages from printing to the console, ensuring the log console stays focused on command executions and errors.

### Key Changes:

1. **Disabled Console Log for Standard Message Events (`src/utils/logger.js`)**
   - Commented out the `process.stdout.write` call inside `botLogger.message` to prevent cluttering the console output.
   - Preserved events and websocket broadcasting for other listeners (e.g. Message Observatory/Web Dashboards).
