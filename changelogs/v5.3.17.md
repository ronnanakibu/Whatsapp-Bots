# Changelog v5.3.17

## 📦 WhatsApp Quoted Message Wrapper Stripping & Silent Drop Fix

This release introduces an automatic quoted-message header unwrap utility to prevent outgoing media, stickers, and texts from being silently dropped by WhatsApp servers when quoting wrapped messages (such as ephemeral or nested view-once structures).

### Key Changes:

1. **Shared Message Unwrapping Utility (`src/utils/message.js`)**
   - Implemented `unwrapMessage(m)` to flatten wrappers recursively.
   - Implemented `getCleanQuoted(msg)` to build a clean Baileys quoted option context by removing wrapper headers.

2. **Applied Clean Quoting Across Handler and Core Media Commands**
   - **`src/handlers/message.js`:** Wrapped all replies (`reply` and `replyMedia`) inside `getCleanQuoted` to ensure standard bot responses are never dropped.
   - **`src/commands/media/sticker.js`:** Applied clean quoting context when sending compiled WebP stickers.
   - **`src/commands/media/dl.js`:** Applied clean quoting context when sending downloaded social videos/audio files.
   - **`src/commands/media/bongkar.js`:** Integrated clean quoting context when returning converted video/images.
   - **`src/commands/media/cosmos.js`:** Integrated clean quoting context when returning Gradio physical AI videos.
