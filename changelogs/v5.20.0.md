# Release Notes v5.20.0

### 👁️ Fitur Baru: Deteksi & Pemulihan Media Sekali Lihat (View Once)
- **Dukungan Penuh Media Sekali Lihat (Foto, Video, Voice Note / Audio):**
  - Bot secara otomatis menangkap seluruh media sekali lihat (*View Once*) yang dikirim di pesan pribadi maupun grup WhatsApp.
  - Mengirimkan preview media utuh secara instan ke nomor WhatsApp Owner beserta informasi pengirim, grup, tipe media, dan caption.
  - Menyediakan opsi konfirmasi interaktif untuk Owner:
    - Balas **`1` / `ya` / `teruskan`**: Bot meneruskan media ke chat/grup asal sebagai media biasa yang dapat dilihat dan diputar berulang kali.
    - Balas **`0` / `ga` / `simpan`**: Bot menyimpan media di arsip lokal tanpa meneruskannya.

### 🛡️ Peningkatan Anti-Delete, Anti-Edit & Memori Permanen (Tanpa Batas Waktu)
- **Eksklusi Pesan Bot Sendiri pada Fitur Anti-Edit & Anti-Delete:**
  - Fitur Anti-Edit dan Anti-Delete kini secara otomatis mengabaikan pesan yang diedit atau dihapus oleh bot itu sendiri, mencegah spam notifikasi palsu ke Owner.
- **Menghapus Batas Waktu Sesi Interaktif (TTL 5 Menit ➔ Permanen):**
  - Seluruh sesi konfirmasi interaktif (Anti-Delete / Anti-Snitch & View Once) kini tersimpan secara persisten di database lokal.
  - Owner dapat membalas `1` atau `0` kapan saja tanpa batas waktu (bahkan setelah berjam-jam atau berhari-hari).
  - Sesi interaktif tetap aktif dan aman meskipun bot direstart.
- **Penyimpanan Media Terhapus Permanen:**
  - File media yang dihapus pengirim langsung diamankan ke penyimpanan lokal secara permanen, menjamin pemulihan media selalu berhasil saat Owner memilih untuk memulihkannya.
