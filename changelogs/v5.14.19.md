# Changelog v5.14.19

## UI/UX Overhaul

### Dashboard — Music Automation Page (Total Redesign)
- **Premium Dark OLED Theme**: Migrated from previous indigo-dominant palette to a deep OLED black (`#09090B`) base with vibrant multi-color accent system (indigo `#6366F1`, violet `#8B5CF6`, emerald `#10B981`, sky `#38BDF8`, rose, amber, pink — each mapped semantically to pipeline stages).
- **Inter Font**: Integrated Google Fonts `Inter` for premium, modern typographic feel across all text elements.
- **Glassmorphism Cards**: All cards use a unified `.glass-card` system with `backdrop-filter: blur(12px)` on desktop; automatically disabled on mobile (≤768px) to preserve performance on 4GB RAM devices.
- **Pipeline Node Cards**: Each node card now has a dynamic glow (`box-shadow`) color matching its stage (e.g. pink glow for Suno Audio, sky glow for Gemini, amber for FFmpeg). Running nodes animate via `opacity` only (no expensive `scale`/`width` repaints).
- **Colored Terminal Logs**: System log output is now color-coded by log prefix tag — errors in rose, success in emerald, warnings in amber, system info in sky, and stage-specific tags in their respective accent colors.
- **Redesigned Terminal Panel**: Macbook-style window chrome (traffic-light circles), line number prefix for each log entry, blinking cursor in empty state.
- **Progress Bar**: Indigo-to-emerald gradient progress bar with smooth motion animation.
- **Engine Selector Buttons**: Cleaner icon+label button grid with per-engine active colors (pink for Suno, sky for Stable, emerald for Manual).
- **YouTube Success Card**: Refined completion card with subtle emerald glow, cleaner copy/watch CTA buttons.
- **Mobile-First Layout**: All animations use `transform` and `opacity` only (GPU-composited) — no width/height/top/left animation. `backdrop-blur` removed on mobile. Static ambient blobs use `fixed` positioning to avoid scroll repaints.
- **Loading & Auth States**: Premium dual-ring loading spinner, polished "Access Denied" screen.

## Technical
- All logic, state, socket listeners, API calls, and form validation preserved identically.
- TypeScript type check passes with zero errors.
