# v5.23.4 (Cloud Vault Storage & Smart Cache Auto-Clean)

## Features
- **Cloud Vault Media Archiving**: View Once (sekali lihat) media and Anti-Delete (revoked) messages are now automatically backed up to a dedicated private cloud channel in real time with comprehensive metadata cards (sender, chat location, original caption, and timestamp).
- **Hybrid Storage Optimization**: Local media cache is now dynamically managed with an automated 1-hour lifecycle purge and strict storage quota safeguards, guaranteeing smooth bot performance and preventing disk saturation on hosting servers.

## Fixes
- **Storage Out-of-Space Prevention**: Implemented automated bootstrap disk sanitization that clears temporary download artifacts and rotates oversize system logs on bot launch to permanently eliminate disk space crashes.
- **View Once & Anti-Delete Reliability**: Enhanced media extraction flow with instant fallback handling, ensuring media payloads are reliably preserved and viewable even when message senders immediately delete them.
