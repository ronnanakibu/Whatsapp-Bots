# v5.23.9 (Robust Message Deletion Engine & Bulk Delete Optimization)

## Fixes
- **Message Store Lookup Crash Fixed**: Resolved a `TypeError` in bulk message deletion where accessing in-memory store records could fail with an undefined property error.
- **Enhanced Group Admin Deletion**: The `.delete` command now supports deleting messages sent by other group participants whenever the bot has administrative privileges in the group.
- **Flexible Bulk Number Parsing**: The delete command now accepts all common format variations (e.g., `.delete 1`, `.delete 5`, `.delete -5`, `.delete --5`) without requiring strict double-dash formatting.
- **Real-Time Outgoing Message Tracking**: Outgoing messages sent by the bot are now immediately registered into fast in-memory storage, allowing instant deletion of recently generated responses.
