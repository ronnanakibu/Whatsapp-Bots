# Changelog v2.0.0 — Radio Platform Backend Rarchitecture (API v2)

Rilis ini merekonstruksi total backend radio streaming RonnBot untuk mendukung fungsionalitas lanjutan di Android APK.

## Fitur & Pembaruan Utama

### 1. Unified SQLite Schema (`src/services/db.js`)
- Migrasi database dengan relasi antartabel untuk: `songs`, `listening_sessions`, `requests`, `dedications`, `play_history`, `reactions`, `favorites`, `achievements`, `achievement_unlocks`, dan `wrapped`.
- Skema *safe migration* otomatis untuk tabel `users` versi lama.
- Inisialisasi data pencapaian (*seeding* default).

### 2. Event-Driven Presence & Gamification Engine (`src/services/radio.js`)
- Integrasi pelacakan durasi dengar real-time melalui parameter `/stream?jid=...`.
- Penambahan Experience Points (XP) per menit mendengarkan secara dinamis.
- Mekanisme kenaikan tingkat (*level-up*) pengguna otomatis.
- Evaluasi otomatis untuk pembukaan pencapaian (*achievements unlock*).

### 3. Modular REST API v2 Router (`src/server/radio.js`)
- Penambahan namespace rute `/api/v2/...` yang terpisah dari status monolitik v1.
- Endpoint baru teruji:
  - **Music**: Search, Request + Dedication, Queue, Play History, Now Playing.
  - **Lyrics**: Mock LRC time-synced lyrics scroll.
  - **Engagement**: Reactions broadcast, Favorites.
  - **Social & Stats**: User Profile, User Stats, Leaderboard Peringkat, Achievements, Annual Wrapped.
  - **System**: Live System metrics.
