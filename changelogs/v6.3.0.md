# Release Notes v6.3.0

## 🌐 Real-Time WhatsApp Group Control & Profile Pictures
- **WhatsApp Group Avatars**: Dashboard kini langsung menampilkan foto profil resmi setiap grup WhatsApp tempat bot aktif secara realtime tanpa data dummy.
- **Official Broadcast Announcement**: Owner bot dapat mengirim pesan pengumuman resmi ke seluruh anggota grup WhatsApp secara langsung melalui antarmuka web.
- **Group Exit Control**: Fitur penarikan bot dari grup yang dipilih dengan sekali klik konfirmasi yang aman dan langsung memutuskan bot dari keanggotaan grup.

## 📻 Live Music Radio Stream & Request Engine
- **Resilient YouTube Music Search**: Pencarian lagu kini kebal terhadap batas header server dan langsung mendeteksi trek YouTube resmi dengan akurasi tinggi.
- **Multi-Layer Audio Stream Pipeline**: Siaran musik radio YouTube dilengkapi proteksi stream berlapis (direct audio extraction, stream piping, dan auto-fallback) untuk mencegah pemutaran terhenti atau gagal memuat.
- **Seamless Live Streaming**: Pemutar radio web kini terhubung langsung ke audio engine siaran bot dengan pemutaran kontinu dan sinkronisasi audio bebas hambatan.
- **Open Song Requests**: Pengunjung dan pendengar web dapat langsung merequest lagu ke antrean siaran bot tanpa perlu login atau terhalang otentikasi.

## 🛰️ Clean Live Message Observatory
- **Zero Placeholder Guarantee**: Tampilan live streaming aktivitas bot kini 100% transparan, hanya menampilkan lalu lintas pesan dan status aktual tanpa data sampel palsu.
- **Real-Time Gateway Health**: Status koneksi multi-device WhatsApp dan metrik penggunaan ditampilkan langsung secara akurat.
