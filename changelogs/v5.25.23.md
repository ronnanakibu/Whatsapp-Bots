# v5.25.23 (Session Auto-Recovery, Web Pairing Portal & Remote Telemetry)

### Features & Improvements
- **Auto-Recovery on Expired Session (401 Disconnect)**: Automatically detects when a WhatsApp session credentials token has expired or been unlinked. The bot autonomously cleans out stale credentials from local disk and cloud storage, immediately generating a new pairing code or QR code to prevent connection hangs.
- **Dedicated Web Pairing & QR Portal**: Introduced a responsive web interface accessible at `/qr`, `/pairing`, and `/code` that renders active 8-digit WhatsApp pairing codes or QR codes directly in your browser, complete with connection status indicators and quick links to live logs.
- **Owner Cloud Session Control**: Introduced `.backup clearsession` for bot owners to remotely purge stale or invalid cloud session snapshots directly from WhatsApp chat.
- **High-Availability Log Telemetry**: Optimized `/api/system/app.log` and `/app.log` endpoints with triple-tier streaming fallback (disk log, console stream, and memory buffer) for frictionless real-time server monitoring from any browser or client.
