# Changelog v5.13.1

## Manual Audio Upload Bug Fix & Drag & Drop Support
- **Manual Upload Route Bug Fix**: Added the missing POST `/api/music/manual-upload` route handler in the backend Express server (`radio.js`), successfully resolving upload network failures (404/500).
- **Multipart Form Upload**: Implemented standard `multer` disk storage to handle manual MP3/WAV files secure transmission, token validation, and pipeline queuing.
- **Drag and Drop Interface**: Added native drag-and-drop file listener support on the Music Dashboard upload container.
- **Interactive Drag Feedback**: Designed seamless green border highlights and scale transitions indicating active file drag over states.
