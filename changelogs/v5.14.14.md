# Changelog v5.14.14

## Bug Fixes
- **FFmpeg-based Audio Probing**: Replaced the missing `ffprobe` binary dependencies for audio duration extraction with an `ffmpeg -i` based regex parser. Since `ffmpeg` is globally available on the remote server container, this ensures audio duration is reliably parsed without throwing "ffprobe not found" errors, allowing the fade-in and fade-out filters to apply properly.
