# Release Notes v3.1.1 - Public Page Scrolling & Radio Health Fixes

This patch release fixes scrolling capability on the public landing page, replaces the direct streaming button with an in-browser audio toggler, and corrects the radio station health indicator state.

## What's New

### 🔓 Restored Page Scrolling
- Programmed dynamic side-effect hooks in [PublicSummary.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/PublicSummary.tsx) to remove `overflow-hidden` constraints from `document.body` and enable `overflow-y-auto` scrolling on layout mount, restoring them cleanly on unmount to keep admin panels fixed.

### 📻 In-Browser Radio Stream Playback Toggler
- Converted the "Listen Live" CTA into a toggle button that controls the in-browser HTML5 Audio stream directly.
- Added a secondary "Direct Audio Link" anchor pointing to `/stream` for external audio players.

### 🟢 Operational Status Health Fix
- Updated the "Radio Station" status indicator inside the health center. The status is now marked `online` whenever the client fetches metadata successfully, rather than depending on whether a track is currently playing.
