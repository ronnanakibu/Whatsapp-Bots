# Changelog v5.13.0

## Google Drive Media Archive Integration
- **Automated Audio Backups**: The raw generated audio (`.mp3`) is now automatically uploaded to a designated Google Drive shared folder right after the YouTube publication step.
- **Dynamic File Renaming**: Audio files are automatically renamed to match their finalized song titles (with sanitized safe characters) before being uploaded to Google Drive.
- **Direct Link Sharing**: Once uploaded, the bot requests direct shareable permissions and provides the Google Drive link directly in both the live dashboard logs and WhatsApp completion messages.
- **Robust Pipeline Fail-safes**: Wrapped the Google Drive backup step in robust error-handling blocks so any storage quota or credential issue will log warnings without crashing the primary YouTube deployment pipeline.
