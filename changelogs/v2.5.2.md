# Release Notes v2.5.2 - Live Controls, DB Inspector & UI fixes

This release addresses UI issues across several dashboard modules and enables live real-time command disabling in the message handler.

## What's New

### 👥 Groups List & Metadata Enhancements
- Updated `getGroupsList` in `radio.js` to parse group subjects, descriptions, member counts, and fetch group avatar URLs in parallel with an in-memory caching mechanism.
- Set up automatic list updating on connection state changes: when the bot status changes to `open`, it schedules a 3-second delayed sync to let Baileys stabilize, then broadcasts updated `groups` and `users` lists to all active dashboards.
- Refactored `Groups.tsx` card styling to use strict overflow boundaries and `line-clamp-2` to prevent layout breakdown on long group descriptions.

### 📜 Real-time Console Log Initialization
- Resolved empty developer console bug: updated the `init` payload handler in `useSocket.ts` to map initialization logs (sent from `getLogHistory()` as raw string lines) into structured `DevLog` objects `{ id, timestamp, text }` before updating the Zustand store.

### 💾 Robust SQLite Query Inspector
- Upgraded the backend `db:query` handler to use `better-sqlite3`'s native `statement.reader` property to determine query type. This provides robust execution routing for all standard SELECT queries as well as complete developer DDL/DML operations (`INSERT`, `UPDATE`, `DROP TABLE`, `CREATE TABLE`).

### ⚡ Live Command Disabling
- Integrated `command.enabled !== false` checking directly into the core `handleIncomingMessage` executor inside `src/handlers/message.js`. Command toggles from the dashboard are now enforced instantly in real-time without requiring server restarts.

### 🖼️ Developer Profile & Branding
- Updated the developer profile view (`Developer.tsx`) with the actual core engineer avatar image (`https://github.com/ronnanakibu.png`).
- Incremented the BotOS dashboard client version to `v2.5.2`.
