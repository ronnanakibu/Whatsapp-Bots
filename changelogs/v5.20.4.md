# Release Notes v5.20.4

### 🔍 Perbaikan Kritis Ekstraksi Pesan Protobuf Baileys
- **Penanganan Metadata Protobuf (messageContextInfo Bypass):**
  - Memperbaiki `unwrapMessage` agar mengabaikan key metadata WhatsApp (`messageContextInfo`, `deviceListMetadata`, `senderKeyDistributionMessage`) dan langsung mengekstrak wrapper `viewOnceMessage`, `ephemeralMessage`, atau konten media sebenarnya.
  - Mengatasi masalah di mana pesan sekali lihat terbaca sebagai tipe `messageContextInfo` sehingga diabaikan oleh filter media.
- **Pencatatan Log Otomatis ke Storage:**
  - Menyimpan salinan seluruh log konsol terminal ke `./storage/logs/console.log` secara persisten.
