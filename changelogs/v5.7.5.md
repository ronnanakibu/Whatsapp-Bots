# v5.7.5 — Custom Sticker Library (Sticker.ly Style)

**Release Date:** 2026-06-22

## ✨ Fitur Baru & Peningkatan

### 1. 🗂️ Fitur Library Stiker Kustom (.lib / .addlib / .addtolib)
- **Fungsi:** Memungkinkan pengguna untuk membuat pack stiker kustom pribadi, menyimpan stiker favorit mereka, dan memanggil stiker tersebut secara instan kapan saja layaknya aplikasi pihak ketiga seperti Sticker.ly.
- **Fitur & Command:**
  - `.addlib [nama]` — Membuat library baru yang terikat pada akun Anda.
  - `.addtolib [nama]` — Menyimpan stiker yang Anda balas (reply) ke dalam library tertentu. Mendukung semua jenis stiker (statis, animasi, anomali/brat).
  - `.listlib` — Melihat semua daftar library stiker yang Anda miliki beserta jumlah stiker di dalamnya.
  - `.showlib [nama]` — Melihat isi detail dari library berupa indeks dan SHA stiker.
  - `.getlib [nama] [indeks]` — Mengambil dan mengirim stiker tertentu dari library berdasarkan indeks ke ruang obrolan.
  - `.delsticker [nama] [indeks]` — Menghapus stiker tertentu dari library Anda.
  - `.dellib [nama]` — Menghapus seluruh library beserta isinya secara permanen.
- **Optimasi Penyimpanan:** Stiker disimpan dengan mekanisme deduplikasi hash SHA-256 pada server untuk menghemat ruang disk jika stiker yang sama disimpan ke dalam beberapa library yang berbeda.
