# Release Notes v2.5.0 - Premium BotOS Dashboard & Unified Server

We have successfully migrated WABOT 2.0 to a unified Bot Operating System (BotOS) architecture.

## What's New

### 🚀 Unified Express & Socket.IO Server
- Replaced the legacy vanilla Node HTTP radio server on port `25637` with a full-blown **Express** backend.
- Integrated **Socket.IO** to handle bi-directional state sync (metrics updates, real-time message streams, developer console logs).
- Retained full compatibility for existing radio audio streaming (`/stream`, `/queue`, `/status`).
- Added robust subdirectory routing:
  - `/dashboard` maps to the new BotOS Panel.
  - `/radio` maps to the legacy Radio Stream Panel.
  - `/` automatically redirects users to `/dashboard`.

### 🎨 Dark-First Next.js 15 Web Dashboard
- Fully configured static SPA export served directly by the Express server.
- Configured custom subdirectory prefix configurations (`basePath: '/dashboard'` and `basePath: '/radio'`).
- Built-out key pages:
  - **Overview**: Active bot connections, system resource grids, and area volume charts.
  - **Message Observatory**: Live kibana-like message stream filters and DM checks.
  - **Analytics**: Advanced trend analysis and command usage distributions.
  - **AI Center**: priority model config fallback chains.
  - **Deployments**: Vercel-like timelines tracking SFTP delta pushes.
  - **Developer**: "Meet the Developer" story and roadmap tracking.
  - **Settings**: Multi-tab panel for token security, providers configurations, and sqlite pruning.
  - **Sidebar Radio Panel Link**: Easily pivot to the stream page with a dedicated external link button (`↗`).

### 🛠️ Build & Compilation Fixes
- Fixed React 19/React Three Fiber peer dependency tree clashes using `--legacy-peer-deps`.
- Patched invalid `@radix-ui/react-badge` package definition in dashboard package.json.
- Corrected imports for Lucide React (`Milestone` singular) and tailwind-merge (`twMerge`).
- Fixed Express 5 wildcards mismatch issues using a path-immune `app.use` fallback handler.

### 📜 Command & Daemon Logs Integration
- Updated `.aboutbots` command in `aboutbots.js` to print both dashboard links directly to WhatsApp rooms.
- Patched bootstrap runner (`start.js`) and radio listener server (`radio.js`) console prints to output correct subdirectory URLs on startup.
