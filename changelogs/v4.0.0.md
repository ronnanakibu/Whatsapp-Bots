# Release Notes v4.0.0 - Major Maintenance Update

This major release resolves issues with megamix timeouts, non-blocking track skips, streaming stability/lag, and synchronizes the radio category commands across WhatsApp and Discord bots.

## What's New

### 📻 Core Radio Stream Optimizations
- **Playlist & Megamix Timeout Fix**: Replaced the 12-minute timeout cap (`Math.min(..., 720)`) with a megamix and live stream friendly calculation (up to 24 hours), resolving automatic stream termination on long videos.
- **Fast Non-Blocking Skip**: Reworked the playback recursion and loop logic in `#playNext()` and `skip()`. Skipping a track now only kills the current process and triggers a brief 200ms grace period instead of awaiting the subsequent track's entire duration.
- **Configurable Bitrate**: Added support for `process.env.RADIO_BITRATE` (defaults to `128k`) to match the ICY headers and ensure maximum stream stability on lower-bandwidth environments.
- **Robust yt-dlp Verify & Fallback**: Implemented a first-chunk listener that waits up to 3 seconds for the `yt-dlp` stream to start writing data. If `yt-dlp` crashes or fails to send bytes early, the bot immediately aborts it and cleanly falls back to SoundCloud / play-dl.
- **YouTube Cookie Arguments for yt-dlp**: Passed `--cookies` from `process.env.YOUTUBE_COOKIE_FILE` or `storage/youtube-cookies.json` to the spawned `yt-dlp` info/stream processes to avoid rate-limiting and throttle-induced audio lag.
- **New `restartCurrent()` Method**: Added a method to unshift the current track back to the queue and skip the stream, allowing voice effect and equalizer modifications to take effect immediately on the current song.

### 📻 WhatsApp Bot Commands
- **Look-Ahead Skip**: Updated the `skip` command to check the queue look-ahead and display the next song instantly.
- **New `fx` (Effect) Command**: Allows users to view and change available voice effects (`normal`, `tupai`, `lambat`, `bass`, `robot`, `reverb`, `louder`) with instant playback restart.
- **New `eq` (Equalizer) Command**: Allows users to view and change available equalizer presets (`flat`, `pop`, `rock`, `jazz`, `bass`, `classic`) with instant playback restart.

### 🤖 Discord Bot Commands Porting & Fixes
- **Fix TypeError Bug**: Replaced the invalid call to `radioService.skipTrack()` with `radioService.skip()`.
- **Look-Ahead Skip**: Integrated look-ahead queue mapping for instant skip feedback.
- **Ported Radio Commands**: Added the following commands to the Discord interface:
  - `!np` / `!nowplaying`
  - `!listener` / `!listeners`
  - `!fx` / `!effect [name]`
  - `!eq` / `!equalizer [name]`
