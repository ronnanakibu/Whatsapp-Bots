# v5.16.3 — Real-Time FFmpeg Rendering Progress & ETA

## New Features
- **Real-Time Video Render Progress Bar**: Implemented real-time stdout/stderr parsing for FFmpeg processes in the playlist loop.
- **Render ETA Tracker**: Calculates and displays dynamic ETA (Estimated Time of Arrival) and progress percentage (`[■■■■□□□□□□□□] XX%`) for each individual track rendering stage, matching the single-song video compile visual telemetry.
