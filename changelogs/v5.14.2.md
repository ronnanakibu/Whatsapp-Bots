# Changelog v5.14.2

## Multi-Candidate Video Generation Fallback Pool
- **Multi-Space Pipeline support**: Implemented a multi-space candidate pool for `generateVideoFromImage` inside `ai.js`.
- **Spaces Integrated**:
  1. `zerogpu-aoti-wan2-2-fp8da-aoti-faster.hf.space` (Primary - Wan 2.2 FP8 lightning AOTI compilation)
  2. `dream2589632147-dream-wan2-2-faster-pro.hf.space` (Wan 2.2 Faster Pro)
  3. `jasfn-ltx-2-3-10eros.hf.space` (LTX-Video 2.3 - 68 positional parameters mapped using defaults)
  4. `techfreakworm-ltx2-3-studio.hf.space` (LTX-Video 2.3 Studio - 17 positional parameter mapping)
- **Automatic Fallback Order**: The pipeline now tries candidate video spaces sequentially. If a space is down, rate-limited, or out of ZeroGPU quota, the bot will gracefully log the error, skip to the next candidate, and download the video output. Only if all candidates fail will the bot fall back to static image rendering.
