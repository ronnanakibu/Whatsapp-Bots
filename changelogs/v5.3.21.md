# Changelog v5.3.21

## 📂 Fix Linux/Pterodactyl Standalone Python Directory Conflict

This release resolves the critical `Permission denied` error encountered when attempting to execute Python commands on the remote Pterodactyl server.

### Key Changes:

1. **Relocate Standalone Python directory (`start.js`)**
   - Moved Python installation path from `./storage/bin/python` to `./storage/python`.
   - This prevents the directory `python` from being placed inside `storage/bin` (which is in `PATH`), avoiding execution clashes where the shell attempted to run a directory and returned `Permission denied`.

2. **Redirect and Capture Setup Logs (`start.js`)**
   - Pip installation output and `u2net` model download logs are now captured and written to `./storage/logs/pip_install.log` and `./storage/logs/model_download.log` respectively, to facilitate troubleshooting on headless/panel environments.
