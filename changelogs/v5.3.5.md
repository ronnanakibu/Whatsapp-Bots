# Changelog v5.3.5 — Audio Streaming Buffer & Stuttering Optimizations

## Performance Improvements & Bug Fixes
- **Optimized yt-dlp Download Client & Buffer**:
  - Changed the default yt-dlp extractor client parameter to `'youtube:player_client=ios,android'` instead of `'android,web'`. The iOS client is significantly more resilient to YouTube's recent signature rate-limiting and throttling algorithms.
  - Increased the download pre-buffer size to `'256k'` (up from yt-dlp's default 1KB buffer). This ensures that minor network speed drops do not instantly empty the download buffer.
- **FFmpeg Thread Queue Size Optimization**:
  - Inserted `'-thread_queue_size', '4096'` before the FFmpeg input `-i`. This allows FFmpeg to queue up to 4096 incoming audio packets in a separate background thread without locking or starving the encoder, eliminating micro-stutters and lags when reading from the stdin pipe.
  - Cleaned up duplicate/redundant `'-re'` flags in the FFmpeg arguments when handling direct URL streams.
