# Changelog v5.3.16

## 📦 Media Detection and Nested Message Wrapper Unwrapping Fixes

This release fixes issues where the bot failed to detect commands on images/videos with captions, or failed to process media/text on quoted/reply messages (such as ephemeral/view-once images, or high-quality image documents).

### Key Changes:

1. **Recursive Wrapper Unwrapping in Message Handler (`src/handlers/message.js`)**
   - Replaced single-level wrapper check with a `while` loop to recursively unwrap deeply nested message structures (e.g. view-once media inside ephemeral messages).
   - Added `documentMessage.caption` to the text extractor, enabling command execution on media sent as documents with captions.

2. **Recursive Wrapper Unwrapping in Sticker Command (`src/commands/media/sticker.js`)**
   - Implemented recursive unwrapping of direct and quoted messages to prevent Baileys' media downloader from choking on nested wrapper formats.
   - Added support for documents containing images/videos.
   - Refactored media type and animation flags detection into robust, type-checked helpers.

3. **Quote Sticker Text Extraction Fix (`src/commands/media/quotesticker.js`)**
   - Implemented recursive unwrapping of quoted messages.
   - Expanded text extraction to retrieve text or caption fields from all nested and media formats cleanly.
