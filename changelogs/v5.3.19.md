# Changelog v5.3.19

## 🎨 Background Removal (--rmbg) Feature Fix & Pterodactyl/Linux Bootstrap Integration

This release resolves issues with the background removal (`--rmbg`) feature for static and animated stickers. It automates system/python dependency installation and model pre-caching during the Pterodactyl server bootloader sequence.

### Key Changes:

1. **Bootstrap Script Integration (`start.js`)**
   - Added a new setup step `setupRembg()` during the boot sequence.
   - Automatically detects the active Python runtime (system `python3`/`python` or the downloaded standalone Linux cpython runtime).
   - Automatically installs `rembg[cpu]` if missing when the bot starts up.
   - Pre-downloads and caches the `u2net.onnx` model file (approx. 176 MB) automatically during startup. This ensures the bot's background removal feature works instantly at runtime without command timeouts.

2. **FFmpeg Path Handling Optimization (`src/services/media.js`)**
   - Wrapped input and output file paths in double quotes within Node's `exec` string templates to prevent syntax errors on paths containing spaces.
   - Refactored directory pattern templates from hardcoded forward-slash combinations to cross-platform `path.join(...)` calls, resolving path parsing failures in Windows environments.
