# Changelog v5.3.23

## 🐛 Fix HTTP Redirect File Download Bug

This release fixes a critical bootstrap bug where downloading assets with redirects (like GitHub releases) resulted in corrupted 0-byte files.

### Key Changes:

1. **Re-engineered downloadFile helper (`start.js`)**
   - Delayed opening the write stream until HTTP redirects are fully resolved and a `200 OK` status is returned.
   - Prevents writing to closed streams or leaving corrupt 0-byte packages (like `python.tar.gz`) on the filesystem when redirects occur.
