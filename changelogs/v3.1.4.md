# Release Notes v3.1.4 - Responsive Admin Tables & Core Rebranding

This patch release improves the usability and aesthetics of the admin console pages on mobile devices by introducing responsive table designs, mobile-friendly page padding, and wrapping layouts. It also completes the rebranding of residual "BotOS" strings to "RonnBot".

## What's New

### 📱 Responsive Tables & Page Layouts for Mobile
- **Responsive User Directory Table**: Refactored [Users.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/Users.tsx) from static 12-column grid rows to responsive card items on mobile screens (`flex flex-col` with helper labels, shifting back to `sm:grid sm:grid-cols-12` columns on desktop).
- **Responsive Live Message Observatory Table**: Modified [MessageObservatory.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/MessageObservatory.tsx) to hide tabular headers on small viewports and render each message event as a clean card block, returning to standard columns on medium viewports (`md:grid md:grid-cols-12`).
- **Responsive AI Moderation Audit Trail Table**: Rewrote row layouts in [Moderation.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/Moderation.tsx) to stack JIDs, warning indicators, and action logs nicely on mobile screens.
- **Node-Builder Wrapping**: Configured workflow triggers and action cards inside [Automations.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/Automations.tsx) to wrap instead of overflowing the container card bounds on small screens.
- **Adaptive Container Padding**: Reduced default main wrapper page padding in [page.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/app/page.tsx) to `p-4` on mobile and scaled it up incrementally (`sm:p-6 md:p-8`) on desktop to avoid squishing page components.

### 🏷️ Final Rebranding to RonnBot
- **Settings Rebranding**: Rebranded "BotOS Web Access Token" label to "RonnBot Web Access Token" in [Settings.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/Settings.tsx).
- **Developer Biography Rebranding**: Renamed "BotOS Odyssey", "BotOS Launch", and metadata panel labels to use "RonnBot" in [Developer.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/app/dashboard/src/components/pages/Developer.tsx).
- **Configuration Bump**: Updated app specifications version keys to `3.1.4` in root and dashboard `package.json` documents and sidebar metadata layout.
