# Release v5.18.0 - Pure Hermes Agent Chatbot Integration

## User-Facing Highlights

- **Pure Hermes Agent Engine**: Integrated NousResearch Hermes Agent as the primary autonomous chatbot engine for all WhatsApp conversations.
- **Direct Agent Routing**: Conversation messages, DM triggers, group mentions, and AI queries now interact directly with Hermes Agent without keyword interference.
- **Agent Health Monitoring**: Added `!hermes` command to inspect Hermes Agent connection status and current agent state directly from WhatsApp.
- **Persistent User Sessions**: Each chat session maintains isolated state and long-term memory managed by Hermes Agent.
