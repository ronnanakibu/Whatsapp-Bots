# Changelog v5.3.13

## 📦 Pterodactyl OpenSSL & Alpine Target Engine Compatibility Fix

This release resolves the database client initialization crash on Alpine Linux based containers due to missing `libssl.so.1.1` shared libraries.

### Key Changes:

1. **Alpine OpenSSL 3.x Compatibility Target**
   - Configured `binaryTargets = ["native", "linux-musl-openssl-3.0.x"]` in `prisma/schema.prisma` generator client settings to download/build the correct engine binary matching Pterodactyl's Alpine host.
2. **Automated Prisma Generation on Boot**
   - Pre-pended `npx prisma generate` to the `npm start` script in `package.json` to ensure client binaries are automatically generated for whichever target OS is currently active on container start.
