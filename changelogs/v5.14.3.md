# Changelog v5.14.3

## Bug Fixes & Optimization
- **Fix Video Generation Crash**: Resolved a critical issue in the motion background generator module where the filesystem utility was not properly loaded, causing video generation to crash and fallback to static images.
- **FFmpeg Progress Log Consolidation**: Fixed a bug where progress logs would flood the dashboard panel and server logs during video rendering on environments without `ffprobe` installed. Transient encoding progress lines are now consolidated into a single updating progress line.
- **Update Google Credentials**: Replaced the corrupted Google Cloud credentials JSON file with a new working service account key, fixing background uploads to Google Drive.
