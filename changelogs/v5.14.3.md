# Changelog v5.14.3

## Bug Fixes & Optimization
- **Fix Video Generation Crash**: Resolved a critical issue in the motion background generator module where the filesystem utility was not properly loaded, causing video generation to crash and fallback to static images.
- **FFmpeg Progress Log Consolidation & CLI Spinner**: Fixed a bug where progress logs would flood the dashboard panel during video rendering on environments without `ffprobe`. Introduced a CLI-style loading spinner and ASCII progress bars to provide real-time updates for rendering, encoding, and YouTube uploads.
- **Update Google Credentials**: Replaced the corrupted Google Cloud credentials JSON file with a new working service account key, fixing background uploads to Google Drive.
- **Creative Story Description & Title Fallback**: Re-engineered the YouTube metadata generator to write engaging, narrative stories based on song prompts instead of listing technical track attributes. Removed the trailing auto-generation credits from video descriptions and resolved a bug to dynamically update active job titles in real time when no custom title is provided.
- **Bootstrap Log Overhaul & Registry Diagnostics**: Redesigned the startup bootstrap runner (`start.js`) to continuously update progress on a single dynamic CLI line rather than spamming multiple lines of checks. Introduced a deep recursive command registry health scanner to automatically identify duplicate command names, aliases, and file loading issues on boot.
- **Enhance Video URL Extraction**: Upgraded the Gradio client output parser for LTX-Video generator candidates to support path and video url key definitions, ensuring successful motion background generation and preventing false fallbacks.
- **Command Loader Dynamic Logging**: Overhauled `src/core/loader.js` to silence the redundant file listings and log all loaded commands on a single dynamic in-place line. Conflicts and loading errors are pushed to new lines for clarity.
- **Detailed ZeroGPU Error Diagnostics**: Integrated direct parsing of HTML-based Hugging Face Space generation failure messages and added dynamic warnings highlighting ZeroGPU quota limits for video generator candidate failures.
- **Support Google Shared Drives**: Added `supportsAllDrives: true` parameters to Google Drive API file creation, permission updates, and link fetching in `gdrive.js` to bypass personal service account storage quotas.
- **Enforce FHD 1080p45 Video Render**: Re-architected all FFmpeg video rendering profiles inside `suno.js` to output Full HD 1080p (1920x1080) at 45 fps using resource-constrained optimization presets (`-threads 2 -preset ultrafast`) to bypass Pterodactyl CPU/RAM container limits.
- **Avoid YouTube AI Flagging**: Configured explicit AI-keyword constraints in the YouTube metadata generator (`ai.js`) to filter out hashtags/references to "AI", "Suno", "Gemini", or automation, preventing automatic "Made with AI" labels.
