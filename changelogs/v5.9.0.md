# v5.9.0 — YouTube Music Video Automation & Web Dashboard Control

**Release Date:** 2026-07-03

## 🚀 Fitur Baru & Peningkatan Automasi

Rilis ini menghadirkan sistem automasi pembuatan video musik instrumen yang terintegrasi secara penuh baik dari WhatsApp maupun panel kontrol web (dashboard). Fitur ini secara dinamis menggabungkan pembuatan lagu instrumen, desain gambar sampul (thumbnail) oleh kecerdasan buatan, visual efek partikel video, serta upload otomatis ke akun YouTube.

### Perbaikan & Fitur Baru:

- **Perintah Pembuat Lagu Otomatis (`!bikinlagu`)**:
  - Menambahkan perintah pemicu baru lewat WhatsApp untuk membuat video musik instrumen secara penuh.
  - Memanfaatkan Gemini AI untuk menyempurnakan prompt mentah dari pengguna serta menghasilkan judul lagu, deskripsi deskriptif, dan tag YouTube yang SEO-friendly.

- **Panel Kontrol Suno Automation Standalone (`/sunoautomation`)**:
  - Menghadirkan halaman antarmuka web khusus Owner dengan desain OLED Dark Mode premium.
  - Fitur pengisian deskripsi/genre lagu dengan opsi toggle **"Sempurnakan dengan AI"**.
  - **Railway-Style Live Pipeline**: Visualisasi progress interaktif node alur kerja (AI Enhance -> Suno Audio -> Gemini Meta -> Thumbnail -> FFmpeg Render -> YouTube Upload -> Complete) yang menyala secara real-time.
  - **Live Console Logs**: Kotak log terminal langsung di dashboard untuk memantau detail proses baris-per-baris (termasuk progress FFmpeg encoding & upload YouTube).
  - **Sesi Keamanan Owner**: Halaman dilindungi token otentikasi dashboard internal untuk mencegah akses ilegal.

- **Peningkatan Tab Automasi Dashboard**:
  - Kartu automasi baru ditambahkan pada tab "Automations" untuk akses cepat satu-klik ke kontrol pipeline `/sunoautomation`.
