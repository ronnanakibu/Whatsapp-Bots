# v5.25.0 (Containerized Cloud Engine & Auto-Sync Session Resilience)

## Features & Improvements
- **Containerized Cloud Architecture**: Optimized the application runtime for modern cloud container platforms with non-root sandbox execution, standard port routing, and integrated health checks.
- **Automated Cloud Session Synchronization**: Introduced a persistent cloud credential backup and restore pipeline. WhatsApp login states are automatically backed up during updates and gracefully restored upon startup, preventing repeated re-pairing during cloud instance restarts.
- **Dynamic Database Schema Auto-Sync**: The database synchronization engine now automatically validates and applies schema updates to cloud databases upon startup without requiring manual intervention.
- **Web QR Code Authentication Portal**: The `/qr` web view provides an interactive, auto-refreshing QR code interface for easy browser-based pairing when initial device authorization is required.
