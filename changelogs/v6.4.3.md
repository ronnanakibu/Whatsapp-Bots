# Release v6.4.3

### Perbaikan & Peningkatan Sistem
- **Stabilitas Autentikasi WhatsApp**: Memperbaiki masalah kegagalan penautan perangkat ("Couldn't link device") pada metode QR Code dan Pairing Code.
- **Pembaruan Protokol WhatsApp Web**: Menyinkronkan versi handshake dengan protokol WhatsApp Web resmi terbaru secara dinamis.
- **Optimasi Penautan Companion Device**: Mengoptimalkan handshake multi-device dan header koneksi untuk mencegah penolakan sesi oleh server WhatsApp.
