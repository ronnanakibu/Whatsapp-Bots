# Changelog v5.14.4

## Feature Enhancements
- **Enhanced YouTube Audio Downloader Fallback**: Upgraded the media downloader pipeline to filter out temporary intermediate processing files (like `.ffmpeg`, `.part`, or `.ytdl`), ensuring that audio downloads consistently resolve to proper playable audio file formats (such as `.mp3`).
- **Send Downloaded Audio as Documents**: Configured the downloader command to deliver downloaded audio files as documents rather than standard audio messages. This preserves the original file name, keeps the files in their native high-quality formats, and makes them easier for users to save directly on their devices.
