# Changelog v5.3.10 — Radio Dashboard Crash Fix

## Bug Fixes
- **Resolved Next.js Client-Side Crash on Radio Dashboard (`/radio` page)**:
  - **Issue**: The server-side Server-Sent Events (SSE) broadcaster `broadcastSSE` was automatically spreading object payloads to add `correlationId` using `{ ...data, correlationId }`. When `data` was a JavaScript array (e.g. the track queue update), this spread operation converted the array into a plain object with index keys (like `{"0": track1, "1": track2, "correlationId": null}`). When received and parsed by the React dashboard, this plain object was stored as the queue state. The dashboard components then called `.slice()` on the queue state, causing a fatal Next.js client-side exception: `TypeError: a.slice is not a function`.
  - **Fix**:
    - Modified `broadcastSSE` and the SSE history missed-event replay handler in [radio.js](file:///d:/CE/JavaScript/BOTS/WABOT2.0/src/server/radio.js) to check if the payload is an array via `Array.isArray(data)`. If it is an array, it is returned intact instead of being spread into an object.
    - Updated client-side Next.js dashboard hooks and components ([useSSE.ts](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/hooks/useSSE.ts), [HomePage.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/pages/HomePage.tsx), [QueueTimeline.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/queue/QueueTimeline.tsx), [SearchPage.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/pages/SearchPage.tsx), [CommandPalette.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/layout/CommandPalette.tsx), [FactoryPage.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/pages/FactoryPage.tsx), and [NetworkPage.tsx](file:///d:/CE/JavaScript/BOTS/WABOT2.0/dashboard/components/pages/NetworkPage.tsx)) with robust fallback checks and type verification (e.g., `Array.isArray(queue) ? queue : []`). This protects the dashboard against any unexpected SSE structure and prevents client-side rendering crashes.
