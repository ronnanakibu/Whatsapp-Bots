# Changelog v5.14.16

## Bug Fixes
- **FFmpeg Filtergraph Label Syntax Correction**: Fixed an issue in `suno.js` where the video output stream label (e.g. `[v_overlay]`, `[v_blend]`, `[v_static]`) was placed in the middle of the comma-separated filter chain (right after `overlay` or `scale` but before `,fade=...`), creating an unconsumed anonymous leaf node. This unconsumed stream had a duration of 0 seconds, which when coupled with the `-shortest` main output flag, forced FFmpeg to prematurely terminate rendering at 1 second. Moved the output stream labels to the very end of the filter chains to ensure correct stream mapping and full-length video outputs.
