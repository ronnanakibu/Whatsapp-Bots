# Release v5.18.7 (Auto Read / Blue Tick Feature)

### ✨ Fitur Baru & Peningkatan
- **Auto Read (Centang Biru / Blue Tick)**: Menambahkan fitur otomatis membaca (mark as read) setiap pesan WhatsApp yang masuk ke bot secara otomatis.
- **Konfigurasi `AUTO_READ`**: Menyediakan opsi konfigurasi `AUTO_READ=true` di file lingkungan (`.env`) agar fitur pembacaan otomatis ini dapat diaktifkan atau dimatikan sesuai kebutuhan.
