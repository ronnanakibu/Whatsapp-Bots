# Release v5.19.0 (AI Voice Transcriber, Web Reader, AI Background Remover & Native WhatsApp Poll)

### ✨ Fitur Baru & Peningkatan
- **AI Voice Note Transcriber & Summarizer (`.transcribe` / `.vn`)**: Mengubah pesan suara (*Voice Note*), audio, atau video note menjadi teks tulisan dan menyajikan ringkasan poin inti secara otomatis.
- **AI Web & Document Reader (`.baca` / `.tldr`)**: Membaca isi artikel web dari tautan atau dokumen PDF dan menghasilkan *Executive Summary* terstruktur (Topik Utama, Poin-Poin Kunci, dan Kesimpulan).
- **AI Background Remover (`.removebg` / `.nobg`)**: Menghapus latar belakang foto menjadi gambar PNG transparan atau stiker transparan (`.nobgsticker` / `--sticker`).
- **Native WhatsApp Poll Creator (`.poll` / `.vote`)**: Membuat voting / polling interaktif resmi WhatsApp dengan pilihan opsi custom untuk grup maupun chat pribadi.
