# Release Notes v5.22.0

### 📸 Integrasi Auto-Archive Instagram Story Website Kelas CE F
- **Sinkronisasi Otomatis Story Instagram (@comeinone.f):**
  - Bot secara berkala memantau story aktif dari akun Instagram kelas, mengunduh foto maupun video story, dan mengunggahnya secara otomatis ke galeri arsip website kelas CE F.
- **Pencegahan Duplikasi Media (Smart Cache Guard):**
  - Dilengkapi sistem pencatatan ID story lokal agar media yang sudah pernah diunggah tidak dikirim berulang kali.
- **Perintah Manual Baru (`!syncstory` & `!poststory`):**
  - **`!syncstory`**: Memaksa bot langsung mengecek story Instagram terbaru dan mengirimkan laporan hasil sinkronisasi secara real-time ke room chat.
  - **`!poststory [caption]`**: Memungkinkan admin dan pengguna mengirimkan foto atau video langsung dari WhatsApp (atau membalas pesan media lama) untuk langsung diarsipkan secara permanen ke website kelas.
- **Notifikasi Terjadwal WhatsApp:**
  - Bot otomatis mengirimkan notifikasi konfirmasi ke room chat atau grup admin setiap kali ada story baru yang berhasil diarsipkan ke website.

### 🚪 Manajemen Grup Dashboard Admin
- **Tombol Keluar Grup Mandiri (Bot Leave Group):**
  - Menambahkan tombol aksi khusus "Keluar" pada setiap kartu grup di halaman Admin Dashboard (Groups Management).
  - Dilengkapi dialog konfirmasi keamanan untuk mencegah ketidaksengajaan keluar grup.
  - Memungkinkan bot meninggalkan grup WhatsApp secara instan langsung dari panel kontrol web.
