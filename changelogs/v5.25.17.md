# v5.25.17 (Live HTTP App Log Streamer & Diagnostic Endpoint)

## Features & Improvements
- **Direct Live App Log Stream (`/api/system/app.log`)**: Users and developers can now directly view live bot activity, errors, and background worker logs directly in any web browser, terminal (`curl`), or automated diagnostic tools without manual file transfers.
- **Smart Tail & Filtering**: The live log endpoint defaults to displaying the most recent 1,000 log lines with instant `text/plain` rendering. It also supports query parameters such as `?lines=500` or `?lines=all` to customize output depth, and `?search=<keyword>` or `?q=<keyword>` to instantly filter specific events (e.g., errors, commands, or downloads).
- **Direct Log Download**: Appending `?download=true` allows one-click downloading of the complete log file (`app.log` or `console.log`) directly to your device.
- **Resilient Fallback Viewer**: If physical disk logs are currently empty, the endpoint automatically streams from in-memory console buffers, ensuring zero-downtime log visibility at all times.
