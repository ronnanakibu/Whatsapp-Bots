# v5.23.8 (Universal Real-Time Media Vault & Standardized Archiving Template)

## Features
- **Universal Real-Time Incoming Media Archiving**: All media received by the bot (photos, videos, voice notes, stickers, and documents) across direct messages and group chats are automatically preserved to the private Cloud Vault in real time.
- **Universal Real-Time Outgoing Media Archiving**: All media uploaded, generated, or sent by the bot (stickers, AI generated images, downloaded media, audio clips, documents) are seamlessly intercepted and archived in real time.
- **Standardized Cloud Vault Template**: Media captions in the storage vault now follow a clean, consistent format detailing Activity, Media Type, Parsed Sender, Group Name or Direct Message origin, Timestamp (WIB), and File Size.
- **Intelligent Deduplication & Caching**: Added in-memory group name caching and buffer debouncing to eliminate duplicate media uploads during active message sequences while keeping memory footprint minimal.
