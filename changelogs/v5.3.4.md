# Changelog v5.3.4 — FFmpeg Obsolete 'afifo' Filter Crash Fix

## Bug Fixes
- **Dynamic FFmpeg 'afifo' Filter Check**:
  - **Issue**: Modern FFmpeg builds (compiled after early 2024, such as the user's March 2026 build) removed the obsolete `afifo` (audio) and `fifo` (video) filters from the codebase. Using these filters caused FFmpeg to crash with `No such filter: 'afifo'`, which prevented live stream playback.
  - **Fix**: Modified `src/services/radio.js` to run a one-time check at startup by executing `ffmpeg -filters` and checking for `afifo` support. The `afifo` filter is now only pushed to the FFmpeg filter chain if it is explicitly supported by the user's installed FFmpeg version. This ensures seamless audio stream playback on both older and modern FFmpeg installations.
