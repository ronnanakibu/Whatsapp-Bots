# Changelog v5.3.2 — Radio Queue SSE Sync & Stream URL Refinement

## Features
- **Real-time Queue SSE/Socket Sync on Track Removal**:
  - Modified the `removeFromQueue(index)` helper inside `src/services/radio.js` to emit the `queue:clear` event when a song is removed from the queue. This forces the Server-Sent Events (SSE) and Socket.IO systems to broadcast the updated queue structure dynamically, ensuring that connected web dashboard clients stay instantly synchronized without waiting for a new track.
- **Copy-Pasteable Stream URL Output**:
  - Replaced the generic `[host]` placeholder in both the WhatsApp `.listener` command (`src/commands/radio/listener.js`) and the Discord `!listener` command (`src/discord/index.js`) with the bot's static stream server address (`ap2.nzb.zelpstore.id`), allowing users to copy-paste the URL directly into VLC or media players.
